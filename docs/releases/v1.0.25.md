# LifeOS 1.0.25 — выпуск Windows и Android

Выпуск объединяет накопленные обновления планирования, карточек действий, аккаунта,
голосового ввода и внутренней архитектуры. Исходники готовятся в ветке
`codex/motion-release-1.0.19`, Windows x64 и universal Android публикуются в
`Russ2345vg/LifeOS-Releases`.

## Совместимость

- Перенесены ранее опубликованные исправления 1.0.23–1.0.24 из отдельной ветки:
  Android JNI `getPluginManager`, tracked TauriActivity, Gradle path check,
  точный выбор release APK, Windows Path, единая frontend сборка и мобильная навигация сна.
- Память жизни поставляется в фазе A: `VITE_LIFEOS_MEMORY_ENABLED=false`.
- Перед выбором главного направления месяца обновить все связанные устройства:
  старый клиент не понимает `monthly_direction_focus` и остановит pull.
- Установить поверх существующего приложения, без удаления и очистки данных.

## Проверки

- `npm run test:release`: 12/12 PASS, включая Android JNI guard и выбор APK.
- Полный E2E: 221 PASS, 20 штатных skips, 5 failures, 1122.42 s.
  Четыре failures — устаревшие ожидания browser account UI после введения честного
  unavailable состояния; один — отсутствовавшее released исправление mobile nav.
- Причины локализованы. После исправления smoke/routes и nav: 4/4 PASS;
  отдельный quick-access/account: 2/2 PASS desktop/mobile. Проверка черновика сохранена
  через реальный PlannerWorkspace в fixture с доступным account service, без live auth.
  Все ранее упавшие cases закрыты; полный suite не повторяли после локализованных правок.
- Финальный `npm run verify`: PASS, exit 0. Typecheck/lint/build/format/Git hygiene,
  1868 unit/integration + 60 infra + 1 alpha — PASS; 1 прежний skip.
  Остались 4 прежних lint warnings и предупреждение о размере bundle.
- Windows x64 + Android universal release build: PASS, exit 0, 804.15 s.
  JNI guard подтвердил сохранность `getPluginManager` после оптимизации.
- Windows FileVersion/ProductVersion: `1.0.25`, updater signature совпадает с манифестом.
- Android: `com.lifeos.desktop`, versionName `1.0.25`, versionCode `1000025`, min SDK 24,
  arm64-v8a/armeabi-v7a/x86/x86_64. `apksigner verify`: PASS, прежний RSA4096 сертификат
  `f3669cd0ca91cd17670e01a284d07493330bcaf32d4993cfbb88ca5099d92c69`.
- Независимый read-only review выявил потерянный Android hotfix; он восстановлен.
  Других конкретных дефектов account/migrations/voice registration не обнаружено.
  Повторный review изменений E2E подтвердил сохранность покрытия и достаточность scoped повторов.

Native startup, микрофон и live account/recovery/sync между установленными устройствами
ещё требуют ручной QA. Browser-проверки не подтверждают эти физические сценарии.
Пакеты не устанавливаются на пользовательские устройства автоматически этой задачей.
