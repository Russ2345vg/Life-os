# LifeOS 1.0.34 — автопилот дня

## Что изменилось

- На странице «Сегодня» появилась команда «Собрать мой день»: LifeOS предлагает временную сетку для уже выбранных задач, не применяя её без подтверждения.
- Главное действие ставится первым, затем учитываются приоритет, оценки длительности, доступное время и пятиминутные переходы между блоками.
- В плане всегда остаётся резерв: 15% дня, минимум 30 минут; после подтверждённой короткой ночи резерв увеличивается до 25%.
- Preview показывает допущения, сохранённые окна и задачи, которые не помещаются. При пересборке будущие окна меняются одной атомарной операцией.
- Активные рабочие сессии и уже начавшиеся блоки защищены. Если данные или время изменились до подтверждения, LifeOS просит собрать свежий план.

## Установка

Подписанный установщик Windows устанавливается поверх текущей версии LifeOS. Не удаляйте прежнее приложение и не очищайте его данные.

После публикации требуется ручная проверка установки поверх предыдущей версии на физическом Windows-компьютере с сохранением существующих записей.
