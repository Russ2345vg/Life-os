# LifeOS 1.0.24 — исправление запуска Android

[Скачать для Android](https://github.com/Russ2345vg/LifeOS-Releases/releases/download/v1.0.24/LifeOS_1.0.24_android_release.apk)
· [Скачать для Windows](https://github.com/Russ2345vg/LifeOS-Releases/releases/download/v1.0.24/LifeOS_1.0.24_x64-setup.exe)

## Что исправлено

- Исправлен мгновенный вылет Android-приложения после обновления до 1.0.23.
- Релизная проверка теперь останавливает сборку, если оптимизатор удаляет обязательный JNI-мост Tauri.
- Функции и данные LifeOS не изменялись.

## Установка и обновление

Установите 1.0.24 поверх существующего LifeOS. Удалять приложение или очищать его данные не нужно.

- **Android 7 и новее:** скачайте `LifeOS_1.0.24_android_release.apk`, откройте файл и подтвердите обновление.
- **Windows x64:** скачайте `LifeOS_1.0.24_x64-setup.exe` и запустите установщик.
