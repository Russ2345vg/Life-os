# LifeOS 1.0.46

Исправлено планирование завтрашнего дня в автопилоте для Windows и Android.

- В «Распорядок → Автопилот дня» добавлен переключатель «Сегодня / Завтра» и дата выбранного дня.
- Выберите «Завтра» и нажмите «Собрать план на завтра». Просмотрите расписание и нажмите «Применить план».
- Выбор дня сохраняется после перезапуска страницы. Пожелания и расписание относятся к своему дню; смена дня сбрасывает старый предпросмотр.
- Все улучшения 1.0.45 сохранены. Аккаунт и синхронизация включены.

На Android установка загруженного обновления подтверждается системным экраном.
