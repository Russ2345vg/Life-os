# LifeOS 1.0.22 — обновления Android

[Скачать для Android](https://github.com/Russ2345vg/LifeOS-Releases/releases/download/v1.0.22/LifeOS_1.0.22_android_release.apk)
· [Скачать для Windows](https://github.com/Russ2345vg/LifeOS-Releases/releases/download/v1.0.22/LifeOS_1.0.22_x64-setup.exe)

Исправлено отсутствие предложения обновиться в Android-приложении.
Интерфейс теперь вызывает существующую проверку Android-канала и показывает
доступную версию в общей карточке «Обновление LifeOS».
Загрузка APK и системный установщик открываются только после нажатия «Обновить».
После отмены системной установки предложение можно повторить или закрыть.

## Однократное обновление старых версий

Версии 1.0.20 и 1.0.21 проверяли обновления только для Windows.
На Android их нужно один раз обновить вручную: скачайте APK по ссылке выше,
откройте его и подтвердите установку поверх имеющегося LifeOS.
Удалять приложение и очищать данные не нужно.

После этого новые Android-выпуски будут проверяться при запуске приложения.
Если установлена последняя версия, карточка обновления не появляется.
Системное подтверждение Android остаётся обязательным.

Все изменения серии 1.0.21 включены в этот выпуск.
Файлы данных остаются локальными; доступ на другом устройстве подключается
через «Аккаунт и синхронизация».
