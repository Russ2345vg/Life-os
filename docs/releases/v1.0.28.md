# LifeOS 1.0.28 — импорт плана

В разделе «Цели» появилась кнопка «Импорт плана». Можно выбрать JSON-файл,
просмотреть направления, цели, сроки и действия, затем добавить их в LifeOS.
Повторный импорт сохраняет существующие записи; после частичного сбоя можно продолжить.

Windows-обновление распространяется через штатный подписанный канал GitHub Releases.
Личные планы в релиз не входят. Android остаётся на опубликованной версии 1.0.27.

Проверки реализации: 15 targeted integration, 2 scoped E2E desktop/mobile,
`npm run verify` (1956 unit/integration, 60 infrastructure, 1 alpha), независимый review.
По явному запросу пользователя на быструю публикацию зелёные проверки не повторяются,
полный E2E не запускается. Для выпуска проверяются сборка, подпись, manifest и публикация.

Опубликован [релиз v1.0.28](https://github.com/Russ2345vg/LifeOS-Releases/releases/tag/v1.0.28).
Подписанная Windows-сборка прошла за 128.35 s; опубликованные `latest.json` и
`android-latest.json` совпадают с подготовленными файлами. Канал Windows указывает на 1.0.28,
Android — на 1.0.27. Исходники версии фиксируются отдельно от бинарного релиза;
личный JSON-план в репозиторий не входит.
