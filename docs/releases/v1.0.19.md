# LifeOS 1.0.19 для Windows

## Что изменилось

- Плавное появление панелей, меню и раскрываемых блоков в текущем Premium-дизайне.
- Отклик кнопок при нажатии, мягкая подсветка основных действий и полей в фокусе.
- Анимация уведомлений и изменения прогресса, более короткие эффекты на небольших экранах.
- Поддержка системного уменьшения движения: эффекты отключаются без изменения работы форм.
- Исправлено отображение синхронизации: соединение с сервером больше не означает, что обмен
  завершён. Ошибки, очередь изменений, конфликты и офлайн имеют отдельные состояния.
- В аккаунте показаны время последнего успешного обмена в текущем сеансе и инструкция
  подключения второго компьютера.

## Установка

Скачайте `LifeOS_1.0.19_x64-setup.exe` из этого выпуска и запустите на компьютере с Windows x64.
При обновлении существующей установки сначала сохраните открытые формы и закройте LifeOS.
Удалять предыдущую версию или очищать данные не требуется.

Для работы с теми же данными на другом ПК откройте «Аккаунт и синхронизация», войдите в тот же
аккаунт и подключите устройство по инструкции. Установка приложения сама по себе не переносит
локальные записи между компьютерами.

Пакет имеет подпись для встроенного обновления LifeOS; это не Windows Authenticode-подпись.
Android-пакет в этом выпуске не обновляется.
