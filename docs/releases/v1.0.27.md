# LifeOS 1.0.27 — управление, обратная связь и память

Статус: исходники и подписанные установщики подготовлены; релиз на GitHub пока черновик.

## Что изменилось

- Действие открывается поверх исходного списка. Можно изменить план, выполнить его и вернуться к прежнему месту работы.
- Завершение действия отделено от обновления экрана и доставки на другое устройство. Повторная попытка после сбоя не создаёт второе выполнение.
- На «Сегодня» доступен выбор конкретного шага к цели и добавление его в план дня с отменой изменения даты.
- Улучшены визуальная иерархия рабочих экранов, доступ к состоянию данных и возврат из раздела аккаунта.
- В «Памяти жизни» появился блок «В этот день»: воспоминания этой даты из прошлых лет с переходом к записи. Уже сохранённые данные используются напрямую; формат хранения и синхронизации не меняется.

## Совместимость и установка

Версия повышается с 1.0.26 до 1.0.27 для Windows и Android. Существующие данные не очищаются. Подписанные EXE/APK устанавливаются поверх текущего LifeOS. После публикации [релиза 1.0.27](https://github.com/Russ2345vg/LifeOS-Releases/releases/tag/v1.0.27) оба манифеста канала обновлений будут указывать на новые пакеты.
