# LifeOS 1.0.30 — OpenAI и восстановление доступа к данным

## Что изменилось

- В настройках аккаунта появился помощник OpenAI: текст вопроса передаётся через сервер LifeOS, без передачи задач и дневника.
- Добавлено восстановление зашифрованных данных сохранённым ключом LifeOS, если Windows больше не открывает прежний защищённый ключ устройства.
- Улучшены сообщения об ошибках входа, загрузки и восстановления, чтобы было понятно, какой шаг требуется.
- Уточнено отображение завершённого действия и его результата.

## Установка

Подписанные установщики Windows и Android устанавливаются поверх текущей версии LifeOS. Не удаляйте прежнее приложение и не очищайте его данные. Для переноса зашифрованных записей на другое устройство понадобится сохранённый ключ восстановления LifeOS.

Проверка установки и синхронизации между двумя физическими устройствами остаётся ручным шагом после публикации.
