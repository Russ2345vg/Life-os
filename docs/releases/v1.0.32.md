# LifeOS 1.0.32 — восстановление аккаунта и синхронизации

## Что исправлено

- В Windows- и Android-сборки снова включена публичная конфигурация аккаунта и зашифрованной синхронизации.
- Экран аккаунта больше не показывает «Синхронизация ещё не настроена» в production-сборке.
- Подготовка релиза теперь останавливается до сборки, если обязательная конфигурация аккаунта отсутствует или синхронизация отключена.
- В релизное окружение загружаются только разрешённые публичные `VITE_*` параметры; серверные ключи в приложение не переносятся.

## Установка

Установите обновление поверх LifeOS 1.0.31. Локальные записи, настройки и данные аккаунта удалять не нужно.
