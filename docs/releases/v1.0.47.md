# LifeOS 1.0.47

Прогулки за 15 минут до заката для Windows и Android.

- Выберите город в настройках прогулки. По умолчанию — Борзя, Забайкальский край.
- Время рассчитывается по координатам и часовому поясу выбранного города без ежедневного запроса к серверу.
- Связанные действия, «Сегодня», календарь, распорядок и автопилот используют одно время прогулки, включая план на завтра.
- Напоминание «Пора на прогулку» доставляется системой при закрытом окне LifeOS. Для Android нужны разрешения на уведомления и точные будильники; для Windows — работающая ОС с выполненным входом пользователя.
- Напоминания подготовлены на 400 дней и продлеваются при открытии LifeOS. Город и настройки напоминаний выбираются отдельно на каждом устройстве.
- Все улучшения 1.0.46 сохранены. Аккаунт и синхронизация включены.

На Android установка загруженного обновления подтверждается системным экраном.
