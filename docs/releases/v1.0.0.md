# LifeOS v1.0.0

## Release

- Version: `1.0.0`
- Release freeze date: 2026-09-02
- Git tag: `v1.0.0`
- Primary release commit: recorded after the release commit is created

## Purpose

LifeOS v1.0.0 is the first official checkpoint of the current local web application. It freezes
the complete implemented product before separate Desktop and Mobile foundation work begins. This
release does not add Tauri, Android packaging, installers, auto-update, or new product behavior.

## Implemented sections

- **Day:** the selected-day workspace, main and additional decisions, linked actions, current and
  next actions, work sessions, date navigation, day start/recovery, and day completion.
- **Management:** directions, projects, goals, decisions, and actions with their lifecycle,
  relationships, archive/restore operations, and strategic review flows.
- **Routine:** day blocks plus the morning and evening cycles, including persisted recovery and
  navigation for dated routine views.
- **Walks:** planning and execution, decision/routine integration, capture, history, analytics,
  insights, and recovery after leaving or restarting the application.
- **Spheres:** life-area records used by decisions, projects, directions, and day results.
- **History:** chronological read-only results for decisions, actions, work sessions, and completed
  daily flows.
- **Evening analytics:** historical summaries, detected patterns, signals, and recommendations.
- **More / Settings:** local interface preferences and configurable evening-ritual parameters.

## Main user scenarios

- Start or recover a day, plan decisions and actions for a date, work through action sessions, and
  complete the day without losing persisted state.
- Run the morning center through physical activation/execution, mirror, main-action focus,
  shortened-mode configuration, and morning completion/history.
- Run the evening ritual through review, environment, reflection, tomorrow planning, preparation,
  relaxation, sleep check, and final completion, including explicit skip and recovery paths.
- Create and maintain directions, projects, goals, decisions, actions, routine blocks, spheres, and
  their supported lifecycle transitions.
- Plan, start, pause, resume, finish, and review walks connected to decisions and routine entries.
- Inspect history and analytics while keeping historical views read-only.

## Design system state

The release uses the LifeOS Design System v1 language: a graphite dark foundation, gold priority
accent, green active/success states, red error/destructive states, semantic spacing/radius/shadow
and motion tokens, responsive desktop and mobile navigation, reduced-motion support, and shared
accessible controls. The existing visual design is frozen unchanged for this release.

## Known limitations

- Product data is local to the browser profile and is stored in IndexedDB; interface and ritual
  settings use localStorage. Cloud synchronization is not implemented.
- Import, export, and full user-data clearing are not part of this release.
- This checkpoint is the web application only. Desktop/Tauri packaging, Windows installers,
  Android packaging, and auto-update belong to later release stages.
