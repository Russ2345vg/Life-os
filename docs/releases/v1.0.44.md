# LifeOS 1.0.44

Автопилот дня подбирает действия из всего каталога по сохранённому главному фокусу и пожеланиям на день. План учитывает отдых, прогулку, утреннюю и вечернюю подготовку, сон и занятое время. Перед применением можно изменить длительность или убрать действие; сохранённый план доступен после повторного открытия. Обновление для Windows и Android. Аккаунт и синхронизация включены; предпочтения автопилота пока сохраняются отдельно на каждом устройстве.
