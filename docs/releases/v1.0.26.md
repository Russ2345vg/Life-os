# LifeOS 1.0.26 — «Память жизни» включена

В разделе «Память жизни» теперь можно создавать и редактировать воспоминания, добавлять к ним
фотографию, отмечать главное, искать события, удалять и восстанавливать записи. Ответ из дневника
за день, неделю или месяц можно вручную сохранить как отдельное воспоминание. Обзор «Мой год»
собирается из сохранённых событий.

## Установка и совместимость

- Обновите **все связанные устройства до 1.0.26**, чтобы создавать и редактировать воспоминания
  на каждом из них. Клиенты 1.0.24 и старше не понимают новый тип записи синхронизации и могут
  остановить получение событий после первого сохранённого воспоминания.
- Устанавливайте Windows EXE и Android APK поверх существующего приложения. Не удаляйте приложение
  и не очищайте его данные перед обновлением.
- При необходимости запись можно снова выключить при сборке через
  `VITE_LIFEOS_MEMORY_ENABLED=false`; чтение сохранённых воспоминаний при этом остаётся доступным.
