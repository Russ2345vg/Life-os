# LifeOS 1.0.20 для Windows

## Что изменилось

- «Быстрый доступ» открывается кнопкой «Поиск и добавление» или Ctrl/Cmd+K, включая русскую
  раскладку. На компьютере это правая панель, на небольшом экране — полноэкранный интерфейс.
- Общий поиск по действиям, целям, направлениям и сферам с контекстом найденной записи.
- Создание действия из текущего экрана и перенос даты на сегодня, завтра или без даты,
  если состояние действия разрешает такое изменение.
- Сохранение фоновых черновиков при работе с панелью и предупреждение перед переходом
  к найденной записи. Ошибки загрузки и сохранения позволяют повторить операцию.

## Установка

Скачайте `LifeOS_1.0.20_x64-setup.exe` из этого выпуска и запустите на компьютере с Windows x64.
Перед обновлением сохраните открытые формы и закройте LifeOS. Удалять предыдущую версию
или очищать данные не требуется.

Для работы с теми же записями на другом ПК откройте «Аккаунт и синхронизация», войдите
в тот же аккаунт и подключите устройство по инструкции приложения. Установщик сам по себе
не переносит локальные записи между компьютерами.

Пакет имеет подпись для встроенного обновления LifeOS; это не Windows Authenticode-подпись.
Android-пакет в этом выпуске не обновляется.
