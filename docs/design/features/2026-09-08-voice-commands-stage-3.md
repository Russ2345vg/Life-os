# Voice Commands — этап 3

Статус: реализован и проверен в пользовательском flow. Commit и push не выполнялись.

## Контракт

Расширение существующего flow этапа 2. Локальные intent/date/time parsing, нормализация,
временный контекст уточнения, разрешение target и прежнее одноразовое подтверждение.
Никакого LLM API, нового хранилища, постоянного прослушивания, commit или push.

Task — Decision. Дата без времени; CreateDecisionForDate не принимает время. CreateGoal
не принимает deadline. Эти значения распознаются, показываются и снимаются только явным
ответом пользователя «без времени» / «без срока». Время суток не подменяется часом.
Дата без года означает текущий год; прошедшая дата требует уточнения. День недели — ближайший
такой день, включая сегодня; «следующая пятница» — пятница следующей календарной недели.
Несколько дат/времён требуют выбора одного значения. Разбор не меняет содержимое диктовки заметок.

Новые read-only запросы используют существующие application queries/repository port через
application resolver, без аналитического backend. Изменения вызывают CreateDecisionForDate,
CreateGoal, RescheduleDecisionSafely и ConfirmDecisionFromActions. Перенос требует причины,
завершение — фактического результата и уже выполненных действий; эти правила не обходятся.
Идентификатор выбирается только из результатов query, никогда не из interpreter.
Все совпадения показываются без автоматического выбора первого. Перед записью target повторно
проверяется по id/version; устаревший preview не исполняется.

Параметризованные русский язык/даты/время; отмена, missing fields, несколько совпадений,

## Поддерживаемые команды и реальные операции

| Команда           | Примеры                                                                                                                 | Подключение                                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Создание задачи   | «Мне нужно купить продукты», «Завтра в десять мне надо позвонить в банк», «Запланируй звонок в банк на завтра в десять» | CreateDecisionForDate, additional, requireExactDate                                                  |
| Создание цели     | «Хочу поставить цель выучить английский», «Создай цель накопить 300 тысяч до первого декабря»                           | CreateGoal; дата распознаётся, требует явного отказа от неподдерживаемого срока                      |
| Перенос задачи    | «Перенеси задачу купить продукты на пятницу», «Перенеси встречу»                                                        | VoiceTaskResolver → выбор → RescheduleDecisionSafely; причина запрашивается отдельно                 |
| Завершение задачи | «Отметь задачу позвонить в банк выполненной»                                                                            | VoiceTaskResolver → выбор → ConfirmDecisionFromActions; фактический результат запрашивается отдельно |
| Запрос задач      | «Что у меня запланировано на завтра?», «Покажи мои задачи на сегодня»                                                   | GetDecisionsForDate, read-only список в палитре                                                      |
| Активные цели     | «Покажи активные цели»                                                                                                  | GetGoals с active                                                                                    |
| Поиск             | «Найди задачу купить продукты», «Найди цель про квартиру»                                                               | VoiceTaskResolver / GetGoals; все совпадения в read-only списке                                      |
| Навигация         | «Покажи дневник», «Перейди в дневник», «Мне нужны цели», «Открой мои задачи»                                            | Существующий shell callback                                                                          |

Даты: сегодня, завтра, послезавтра, дни недели, следующая календарная неделя, через N дней,
через неделю, число + русский месяц, порядковые числительные («первого декабря»,
«двадцать первого декабря»), DD.MM, DD.MM.YYYY и ISO. Вчера/позавчера распознаются;
для изменяющей команды прошедшая дата требует нового ответа. Несуществующие даты не принимаются.

Время: «в 10», «в 10:30», «в десять утра», «в семь вечера», «в час», «в двадцать три».
Утром/днём/вечером/ночью требуют точного времени или явного «без времени».
Даже точное время **не записывается в задачу**: текущая модель его не хранит. Окно показывает
распознанные часы и предлагает «Продолжить без времени»; только после этого создаётся preview.

## Неоднозначность и уточнения

Интерпретатор возвращает проверяемую структурированную команду либо типизированный
CommandClarification с confidence=needs_input, полем и immutable draft. Неизвестный выход
адаптера, лишние поля, низкая confidence внутри неподдерживаемого формата и выдуманный target ID
не проходят CommandValidator. Замена интерпретатора остаётся за CommandInterpreter;
подключения AIInterpreter/LLM в этом этапе нет.

Контроллер различает interpreting, clarification, selection, preview, executing, success/error.
Два неразрешённых временных вопроса сохраняются независимо. Ответ продолжает draft и не
исполняет его автоматически. При смене вопроса поле ответа очищается. Ошибочный ответ сохраняет
контекст; отсутствие target запрашивает новое название, сохраняя дату/причину/результат.
Редактирование исходной команды начинает новый разбор, Escape/Отмена/закрытие очищают flow.

Поиск targets сопоставляет слова без учёта регистра и ё/е, поддерживает формы слова «встреча».
Он не выбирает ближайшую строку по fuzzy score и не берёт первое совпадение. Deleted/archived и
недоступные для изменения статусы исключены. Все подходящие задачи показываются с датами.
Выбранный immutable id/title/date/version привязан к revision подтверждения. Перед записью
объект перечитывается, несовпадение отклоняет устаревший preview. Перенос дополнительно использует
existing expectedVersion/CAS. Двойной confirm, старый revision и поздняя интерпретация не исполняются.

## Реальные ограничения

- Нет хранения времени задачи и точного срока цели; они не подменяются текстом title, horizon
  или произвольными часами. Суммы остаются частью названия цели без догадок о валюте.
- Завершение не создаёт фиктивных evidence/actions. При отсутствии выполненных действий или
  наличии незавершённых существующая команда возвращает предметную ошибку.
- Перенос требует более поздней даты и причины, может переместить связанные незавершённые
  действия. Этот эффект явно показан в preview. Действующие ограничения сессий и лимитов сохранены.
- ConfirmDecisionFromActions не имеет атомарного expectedVersion/CAS; voice проверяет snapshot
  перед вызовом, но существующую конкурентную гарантию application-команды не усиливает.
- Свободные заметки и записи дневника, удаление, другие изменения целей, цепочки операций,
  wake word, постоянное прослушивание и автономное планирование не подключены.
- Локальный parser не обещает понимание произвольной русской речи. Неподдержанные формулировки
  требуют исправления; грамматика и небольшой словарь расширяются отдельно тестируемыми модулями.

## Точная ручная проверка

Использовать тестовые данные в обычном приложении. На desktop открыть «Голосовые команды» в
левой панели; на mobile — микрофон справа в шапке. Открытие палитры не начинает запись.
Любую фразу можно произнести кнопкой микрофона либо ввести в «Текст команды» и нажать
«Разобрать команду». Диктовку завершить повторным нажатием микрофона или дождаться завершения.

1. «Завтра в десять мне надо купить продукты» → увидеть исходную фразу, дату завтра и 10:00;
   записи ещё нет. Нажать «Продолжить без времени» → проверить дату/title → «Создать» →
   «Открыть задачу». Создаётся ровно одна задача на дату завтра без времени.
2. «Создай цель накопить 300 тысяч до первого декабря» → увидеть 1 декабря текущего года
   и ограничение срока. Если дата уже прошла, сначала уточнить будущую дату. Нажать
   «Продолжить без срока» → «Создать»; цель имеет только поддерживаемые поля.
3. «Открой дневник» → переход без подтверждения; закрыть результат, проверить «Историю».
4. «Что у меня запланировано на завтра?» → список с созданной задачей, без кнопки подтверждения.
   «Покажи активные цели» → только active или явное пустое состояние.
5. Создать две тестовые задачи «Встреча с врачом» и «Встреча с коллегой» на сегодня/завтра.
   «Перенеси встречу» → ответить будущей датой позже обеих, затем причиной; второй вопрос
   имеет пустое поле ответа. Выбрать одну задачу → проверить «Было», «Станет», причину и
   связанные действия → «Изменить». Перемещается только выбранная задача.
6. «Перенеси задачу купить продукты на пятницу» → причина → preview. Если ближайшая пятница
   не позже прежней даты, существующая команда отклоняет перенос; выбрать следующую пятницу.
7. «Добавь задачу купить хлеб завтра или послезавтра вечером» → уточнить дату → увидеть
   отдельный вопрос о времени → «в 11 утра» → явное продолжение без времени → preview.
   Нажать «Отмена»; повторное открытие не содержит старой команды или ответа.
8. «Отметь задачу позвонить в банк выполненной» → указать фактический результат → выбрать
   задачу при нескольких совпадениях → «Завершить». Без выполненных связанных действий
   показывается ошибка; с уже выполненными действиями и без незавершённых задача подтверждается.
9. Повторить desktop/mobile: Tab/Shift+Tab удерживают фокус в окне, Escape отменяет flow,
   кнопки доступны, текст и список не выходят за экран, console без новых ошибок.

Аппаратный микрофон и качество внешнего распознавания проверяются на устройстве пользователя.
Автоматические браузерные сценарии используют fake speech provider и реальные application writes.
