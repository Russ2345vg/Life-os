# Итоги выполненных действий в целях и направлениях

**Статус:** реализация в существующих экранах, 04.10.2026.

После выполнения действия пользователь может записать итог. Экран цели показывает итоги связанных выполненных действий, экран направления — итоги как действий с прямой привязкой к направлению, так и действий целей этого направления. Записи читаются из `LifeAction.actualResult`; отдельного хранения и миграции нет.

`FEATURE → USER GOAL → EXISTING LOGIC → PAGE/COMPONENT ARCHETYPE → SECTION COLOR → MAIN VISUAL CENTER → COMPONENTS TO REUSE → MOBILE BEHAVIOR → APPROVED REFERENCE → TEST SCOPE`

`Итоги действий → видеть результаты в контексте цели и направления → LifeAction.actualResult → существующие карточка цели и страницы цели/направления → общий jade → текст результата с названием действия и датой → PlannerGoalList, PlanningGoalDetail, BalanceWorkspace → одноколоночный список → стандартный UI, отдельный макет не требуется → выборка контекста, render, desktop/mobile`

Пустое состояние явно говорит, что записанных итогов пока нет. Удалённые действия исключаются; архивные выполненные действия сохраняют историю. Записи идут от новых к старым и дают ссылку на действие.
