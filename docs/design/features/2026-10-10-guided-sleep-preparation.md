# Пошаговая вечерняя подготовка — пункт 6

Пользователь подтвердил короткий дизайн 10.10.2026 («lf», то есть «да»).
Это функция существующей страницы `/#/v2/sleep`, без новых application-контрактов.

FEATURE → пройти текущую подготовку по шагам.
USER GOAL → видеть одно действие, прогресс и завершение рядом.
EXISTING LOGIC → NightCycle snapshot, completePreparationItem и finishPreparation.
PAGE ARCHETYPE → текущий checklist с компактным inline режимом.
SECTION COLOR → действующие Graphite/Jade tokens.
MAIN VISUAL CENTER → текущий невыполненный пункт.
REUSE → existing buttons, progress, checklist и application callbacks.
MOBILE → один столбец, touch ≥44px, без horizontal overflow.
REFERENCE → текущий вечерний экран из sleep-quick-entry-qa; новая палитра не нужна.
TEST SCOPE → selector/timer, render states, scoped preparation desktop/mobile.

«Начать подготовку» открывает первый PENDING-пункт из текущего snapshot, в его порядке.
«Готово — следующий» вызывает существующую команду; шаг меняется только после сохранения
отметки. При ошибке он остаётся текущим и доступен повтор. Последний пункт завершает
подготовку существующим ALL_DONE. Рядом есть «Завершить с пропусками» с прежней WITH_SKIPS
семантикой и «К списку». Пустой/завершённый/пропущенный список не предлагает новый старт.

Для любого шага можно вручную запустить таймер на 1–120 целых минут, исходно 3 минуты.
Пауза, продолжение и сброс доступны рядом. Остаток считается по deadline, не по числу ticks.
Окончание таймера не ставит DONE. Таймер — состояние открытого раздела; при выходе/перезапуске
сбрасывается. Выполненные пункты остаются сохранёнными: новый старт продолжает с первого
невыполненного. Таймер фоновой службы Android, системные уведомления и настройки шаблонов
не входят в пункт 6. Смена ночи сбрасывает transient UI по cycle ID.

Предыдущие незакоммиченные улучшения сна сохраняются. Release/version/feed не меняются.
