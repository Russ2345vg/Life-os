# Понятный старт в сферах

## Дизайн-контракт

- FEATURE: доработка существующей страницы сфер и существующего сценария оценки.
- USER GOAL: выбрать сферы и поставить первую оценку без поиска по настройкам.
- EXISTING LOGIC: BalanceState и projectLifeBalance — источник отображения; UpdateSphere и
  CreateSphere — единственный путь сохранения. Manual override и расчёт attentionNeed сохраняются.
- PAGE/COMPONENT ARCHETYPE: обзор состояния с компактным приглашением при отсутствии данных.
- SECTION COLOR: общий тёплый акцент. Графитовая атмосфера существующей темы.
- MAIN VISUAL CENTER: следующий шаг настройки до появления данных; колесо после первой оценки.
- COMPONENTS TO REUSE: BalanceWorkspace, BalanceWheel, BalanceEntityForm, BalanceForm,
  ScoreField, PlannerSheet, существующие настройки включения сфер и design tokens.
- MOBILE BEHAVIOR: один столбец, поля и кнопки от 44 px, поле оценки первым в форме оценки.
- APPROVED REFERENCE: согласованный пользователем план и существующий UI; стандартная форма
  и empty state не требуют отдельного макета. Новый раздел или мастер не создаётся.
- STATES: loading/error/retry сохраняются; no active spheres / no selected spheres /
  selected but unrated / partially rated / fully rated различаются. Save busy/error/cancel
  используют существующую форму. Ноль — оценка, null — отсутствие данных.
- TEST SCOPE: render tests состояний, существующие scoring/command tests, scoped E2E пути от
  выбора сфер к оценке, отмена, сохранение нуля, конфликт версии и автоматический расчёт;
  verify, desktop/mobile QA и Правило №38.

## Решения

1. Нет активных сфер: «Создать первую сферу» открывает существующую форму. Архив не возвращается
   автоматически. Активные сферы не выбраны: «Выбрать сферы» раскрывает существующие настройки.
2. Колесо выбрано, но оценки отсутствуют: «Оценить первую сферу» открывает первую выбранную
   неоценённую сферу. При частичном заполнении доступно «Оценить следующую сферу».
3. Счётчик использует effectiveScore выбранных активных сфер; учитывает ручные и автоматические
   оценки. Пустое колесо не показывает 0 из 0. После сохранения projection перечитывается.
4. Существующая кнопка оценки на карточке открывает ту же форму в режиме оценки: ручная оценка
   и желаемый уровень сначала, остальные поля ниже. Автоматический результат показан отдельно;
   он не копируется в поле manualScore. Пустое поле сохраняет автоматический расчёт.
5. Для сравнения нужны effectiveScore и desiredLevel. Отсутствие сравнимых сфер не означает
   отсутствие дефицита; при частичных данных это явно обозначается. Расчёт не меняется.

## Границы

Без новых зависимостей, схем хранения, автозаполнения оценок, изменения архивных данных,
обязательного onboarding или публикации. Ранее внесённые изменения сохраняются.
