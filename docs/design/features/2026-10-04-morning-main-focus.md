# Утренний фокус по главной задаче дня

## Цель

Пользователь сам выбирает одно главное действие в плане дня. Утренний ритуал помогает отработать над ним минимум 60 минут чистого времени через Pomodoro 25/5. Три полных рабочих интервала, 75 минут, служат рекомендуемым ориентиром. Перерывы не входят в зачёт; завершение утреннего фокуса не завершает само действие.

## Контракт

Функция существующей страницы «Сегодня» → главное действие дня из `GetPlannerToday.main` → существующий `ActionPomodoro` и `WorkSessions` → стандартный блок над планом → графитовая поверхность, jade для запуска, зелёный только для достижения минимума → задача и прогресс к 60 минутам → один столбец на mobile. Общее утверждённое направление: [«Единая рабочая поверхность»](../references/2026-09-25-premium/approved-direction.png).

Пустое состояние предлагает выбрать главное действие в плане. По запуску Pomodoro связывается с датой и действием. Существующая `ActionSession` остаётся источником фактически отработанного времени, включая паузы и перерывы. Локальная запись хранит только идентификаторы сессий и исходные показания при входе в утренний фокус, чтобы обычная работа над той же задачей не засчитывалась задним числом. Утренний минимум достигнут при 60 минутах чистой работы; отсчёт может продолжаться до конца третьего интервала. Смена главного действия не завершает старую сессию и не переносит её время в новое действие.

## Проверка

Расчёт 25/5, переход через 60 и 75 минут, изоляция другой сессии и ранее отработанного времени; рендер пустого и заполненного блока; scoped E2E desktop/mobile, keyboard/focus и console; `verify`. Полный E2E не требуется для локального сценария.
