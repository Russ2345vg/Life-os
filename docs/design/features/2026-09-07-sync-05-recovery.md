# SYNC-05 — Вложения и восстановление

Новая функция существующего экрана «Синхронизация», без нового раздела и без SYNC-06 polish.
Архитектура и scope заданы утверждёнными LifeOS_Sync_v1_Design.md и SYNC-05 task.

Сохраняется существующий settings archetype: SectionPageHeader и главный sync status,
затем стандартные Graphite Panel с вложениями, историей конфликтов, Недавно удалёнными
и резервными снимками. Акцент — существующее золото, атмосфера — тихий графитовый градиент.
Новый approved reference не требуется: используются принятые панели/списки/кнопки настроек.

Состояния: loading с сохранением структуры; пустые списки; inline error/retry;
отдельное подтверждение restore; успешный local snapshot явно отличается от cloud verified.
Preview показывает изменения/добавления/удаления, совместимость и доступность вложений.
Любой restore сначала создаёт и проверяет снимок текущего состояния.

Mobile: вертикальный поток, перенос действий, 44px controls, длинные значения переносятся.
Контрольная проверка — desktop 1366×900 и mobile 390×844, keyboard/focus, overflow и console.
Статус документа: implementation specification, не визуальное APPROVED/LOCKED.
