| Требование                            | Реализация и проверка                                                                                                                                                                                     |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Создание в контексте направления/цели | Формы получают реальные идентификаторы; application-команда наследует сферу и отклоняет конфликт направления и цели. Integration и browser tests.                                                         |

| Иерархия                              | Сфера / направление / цель вычисляются по связям, включая прямую связь действия без цели с направлением.                                                                                                  |
| Одна строка серии в выборе            | Общий application selector возвращает ruleId; распорядок и периоды сохраняют серию, выбор конкретного дня разрешает датированный экземпляр. Тест на 100 экземпляров, две серии, обычное действие и поиск. |
| История повторений                    | Существующие RecurrenceRule и LifeAction сохранены. Count-серия не переносит уже назначенный экземпляр на другую дату; прошлые даты не материализуются.                                                   |
| Маркер повторения                     | Общий outline badge и краткое расписание; существующий счётчик выполнения цели сохранён. Native select использует текстовую метку повторения.                                                             |
| Необязательный результат              | actualResult принадлежит конкретному выполнению; completionKey защищает от сохранения устаревшей формы после reopen. Следующий экземпляр пуст. Integration и browser reload tests.                        |
| Persistence и sync                    | Новые поля необязательны для старых записей; добавлены ссылки direction/rule в registry; routine/period roundtrip проверен.                                                                               |

## Визуальная проверка по Правилу №38

Проверены снимки Chromium 1440 px и 390 px: длинное название переносится, контекст остаётся вторичным, результат свёрнут до запроса пользователя, виден keyboard focus, горизонтальной прокрутки нет. На mobile форма распорядка становится вертикальной и прокручивается; сохранение доступно в browser flow. Поле поиска использует существующий класс полей распорядка.

Использованы существующие формы, списки, фильтры, VoiceField и VoiceTextArea. Новая палитра, декоративное свечение и анимации не вводились. Состояния результата: disabled во время сохранения и при пустом тексте, inline error с повторной отправкой, success feedback. Пустое направление и недоступная серия имеют существующее текстовое пояснение. Смысл повторения передан иконкой и текстом.

Это review добавленных элементов в текущем интерфейсе V2, без утверждения нового визуального эталона. Нативная экранная клавиатура физического телефона не проверялась; проверены mobile viewport, фокус и сохранение формы в браузере.
