# Память жизни — «В этот день»

Статус: реализация разрешена продолжением задачи 01.10.2026. Визуальный результат ещё не утверждён отдельно. Основа — утверждённый раздел «Память жизни» и его текущие карточки.

## Цель и поведение

На странице памяти показывать сохранённые воспоминания с той же локальной календарной датой из прошлых лет. Для каждого указать год, сколько лет прошло, название, короткий текст и фотографию при наличии. Нажатие открывает существующий просмотр воспоминания. Записи текущего года, будущие и мягко удалённые не показывать. 29 февраля совпадает только с 29 февраля.

Данные читаются из `memoryEvents` через `MemoryRepository`. Список не создаёт новые события и не меняет схему IndexedDB, синхронизацию или пользовательские записи. Порядок — от ближайшего года к старому, затем существующий порядок внутри даты. Фото загружается существующим ленивым preview; список содержит только metadata.

## Дизайн-контракт

```text
FEATURE → новая функция существующей страницы «Память жизни»
USER GOAL → быстро вернуться к событиям этой даты из прошлых лет
EXISTING LOGIC → MemoryEvent, byOccurrence index, MemoryQueries, MemoryPhotoPreview, detail sheet
PAGE/COMPONENT ARCHETYPE → существующая лента, компактный обзор над фильтрами
SECTION COLOR → общий тёплый акцент темы; нейтральные поверхности без новой палитры
ATMOSPHERIC MOTIF → личный альбом, где фотография пользователя является содержимым
MAIN VISUAL CENTER → лента воспоминаний; «В этот день» — вторичная обзорная зона
COMPONENTS TO REUSE → memory-surface, MemoryPhotoPreview, planner-muted, detail sheet
MOBILE BEHAVIOR → одна колонка, touch targets не меньше 44 px, без горизонтального overflow
APPROVED REFERENCE → NO для нового блока; стандартная композиция из утверждённых компонентов
TEST SCOPE → repository/application/UI targeted; scoped memory E2E при доступном browser gate
```

Загрузка показывает спокойное состояние без скачка в структуре. При отсутствии совпадений — короткое объяснение, что здесь появятся события этой даты из других лет. При ошибке — текст и «Повторить». После синхронизации, сохранения, удаления, восстановления и смены даты данные обновляются вместе со страницей. Успешное открытие использует существующую панель; нового сообщения об успехе не нужно.

## Проверка

Проверить совпадение месяца и дня, границу года, 29 февраля, исключение удалённых, сортировку, отсутствие фото-байтов в выдаче и переход в существующий просмотр. Desktop/mobile и чек-лист правила №38 — часть визуальной проверки. Если локальный браузер заблокирован средой, это ограничение явно указать в отчёте, не подменять его историческим снимком.
