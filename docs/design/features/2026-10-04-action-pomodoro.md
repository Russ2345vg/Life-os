# Фокус по действию: помодоро

**Статус:** проект на визуальное согласование, 04.10.2026.

## Цель и контракт

Пользователь выбирает открытое действие через «⋯» или правый клик, нажимает «Начать фокус» и получает таймер, привязанный к этому действию. Фокусное рабочее время сохраняется в существующих рабочих сессиях и отчёте «Рабочее время»; перерывы туда не входят. Действие не отмечается выполненным автоматически.

`FEATURE → USER GOAL → EXISTING LOGIC → PAGE/COMPONENT ARCHETYPE → SECTION COLOR → MAIN VISUAL CENTER → COMPONENTS TO REUSE → MOBILE BEHAVIOR → APPROVED REFERENCE → TEST SCOPE`

`Помодоро действия → работать короткими фокусными отрезками → WorkSessions и EntityContextMenu → PlannerSheet из списка/Сегодня → общий jade-акцент → крупный отсчёт → PlannerSheet, EntityContextMenu, WorkSessions → панель на всю ширину с кнопками ≥44 px → NO, макеты ниже ожидают approval → расчёт фаз, переходы, браузерный сценарий desktop/mobile`

## Поведение

- Пункт «Начать фокус» доступен для открытых действий в общем меню `EntityContextMenu` на экранах «Сегодня» и «Действия»; меню одинаково открывается через «⋯», правый клик и долгое нажатие.
- Пункт открывает панель с названием действия, фазой и обратным отсчётом. Пользователь нажимает «Начать фокус», после чего начинается рабочая сессия. Длительность по умолчанию: фокус 25 минут, короткий перерыв 5 минут, длинный перерыв 15 минут после четырёх фокусных отрезков.
- Во время фокуса доступны пауза/продолжение и завершение. На нуле рабочая сессия ставится на паузу и начинается перерыв; перерыв не прибавляет рабочее время. После перерыва следующий фокус запускается вручную, чтобы отсутствие пользователя не записывалось как работа.
- При закрытии панели отсчёт продолжается; компактный индикатор в оболочке показывает фазу и оставшееся время и открывает панель обратно. Перезагрузка восстанавливает фазу и дедлайн из локального состояния, сверяя их с существующей рабочей сессией. Источником фактически отработанного времени остаётся `WorkSessions`.
- Одновременно допускается один активный помодоро. Если уже идёт сессия другого действия, панель объясняет конфликт и предлагает открыть «Рабочее время» для завершения той сессии.
- Ошибка старта, паузы или завершения остаётся видимой с повтором действия; таймер не показывает успешное состояние до подтверждения команды. Если действие удалено или архивировано, панель сохраняет читаемое название и даёт завершить сессию.

## Визуальная основа

Текущий экран `#/v2/actions` активного worktree проверен на desktop 1280×800 и mobile 320/390 px. Используются графитовые поверхности, системный шрифт, jade для основного действия и кольца отсчёта, текущие токены и каскад `tokens.css → planner-v2.css → planner-master.css → planner-premium.css`. Главный центр панели — оставшееся время. Состояния: до старта, фокус, пауза, перерыв, готовность к следующему фокусу, ошибка.
