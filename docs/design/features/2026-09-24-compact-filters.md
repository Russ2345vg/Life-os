# Компактные фильтры целей и действий

## Дизайн-контракт

- FEATURE: улучшение фильтров существующих списков.
- USER GOAL: быстрее видеть содержимое и понимать выбранные условия.
- EXISTING LOGIC: локальное состояние Presentation; существующие filterPlannerGoals,
  filterPlannerActions, filterGoalsByPeriod. Domain, application и persistence не меняются.
- PAGE/COMPONENT ARCHETYPE: рабочий список с раскрываемой панелью фильтров.
- SECTION COLOR: общий тёплый акцент; текущая графитовая атмосфера.
- MAIN VISUAL CENTER: список целей или действий.
- COMPONENTS TO REUSE: VoiceField, VoiceTextInput, planner-filter-panel, стандартные select,
  checkbox, button, planner-active-filters и tokens. Новый shared-компонент не нужен.
- MOBILE BEHAVIOR: поиск и кнопка фильтров; дополнительные параметры по раскрытию,
  один столбец полей, два столбца категорий действий, зоны нажатия от 44 px.
- APPROVED REFERENCE: существующий язык и разрешённая пользователем доработка фильтров;
  отдельный макет для стандартного интерфейса не требуется.
- STATES: загрузка и ошибка периодов сохраняются; при пустом результате доступны пояснение и
  полный сброс. Изменения фильтров сразу применяются, «Показать» закрывает панель.
- TEST SCOPE: существующие model/render tests, новые scoped browser tests фильтрации,
  счётчика, очистки периода, клавиатуры и responsive; общий verify.

## Поведение

Счётчик считает активные условия, включая период и категорию действий. Поиск и сортировка
не входят в число фильтров. Выбранные условия видны снаружи и снимаются по одному.
«Сбросить все» очищает условия, а «Сбросить фильтры и поиск» также очищает поиск.
Escape и «Показать» возвращают фокус на кнопку фильтров.

Период планирования отделён от горизонта цели и даты завершения. «Сейчас» означает намерение
заниматься целью сейчас, а не включение в неделю. «Без периода» означает отсутствие действующих
связей с любым периодом, включая прошлые; это не проверка срока. «Без даты завершения» проверяет
только отсутствие dueDate. Существующие правила отбора сохраняются.

Область изменений: PlannerGoalList, PlannerActionList, локальные стили и browser tests.
Переключение списка/канбана/календаря остаётся отдельным управлением представлением.
