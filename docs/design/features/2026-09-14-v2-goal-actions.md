# V2 Goal: действия в карточке результата

Раздел: «Цели», существующая страница Goal. Цель пользователя — видеть желаемый результат, ближайший шаг и все связанные LifeAction в одном месте. Источник связи — существующий `LifeAction.goalId`; создание, планирование и завершение проходят через действующие application-команды.

Композиция: заголовок и компактный контекст (сфера, направление, статус, важность, горизонт, срок), желаемый результат, настоящий прогресс для измеряемой цели, отдельный ближайший шаг, открытые действия, свёрнутые выполненные, вторичная свёрнутая история. Для качественной цели процент не выводится. Этапы не используются для группировки без надёжной связи Action → Stage.

Визуальный язык: существующий тёмный V2, один тёплый акцент, минимум рамок; главный центр — результат и следующий шаг. На 390/360/320 px блоки выстраиваются вертикально, ссылки и галочки остаются доступными без горизонтальной прокрутки. Состояния: загрузка, пустой список, ошибка команды и успешное обновление. Отдельный approved reference не нужен: экран собирается из текущих V2 компонентов и архетипа страницы Goal.

Проверка: выборка по `goalId`, next/completed, форма с зафиксированной целью, возвращение к цели после создания, существующий completion flow, количественный/качественный прогресс, мобильная компоновка; targeted tests, затем один `npm run verify` без полного E2E.
