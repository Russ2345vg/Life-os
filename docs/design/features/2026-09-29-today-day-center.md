# «Центр дня» на вкладке «Сегодня»

Статус: согласовано пользователем 2026-09-29 как следующий этап улучшения блока «План на сегодня».

## Дизайн-контракт

FEATURE: обновление существующего блока «План на сегодня» без новой предметной логики.

USER GOAL: сразу видеть состояние плана, быстро добавить действие и перейти к главному действию
или списку без визуально разрозненных панелей.

EXISTING LOGIC: `PlannerTodayOverview`, расчёт расписания, сценарии и существующие application-
команды остаются источниками состояния и изменений.

PAGE/COMPONENT ARCHETYPE: центр управления днём в основной колонке архетипа Today 8+4.

SECTION COLOR: графитовые поверхности и jade для основного действия; золото сохраняется только у
главного приоритета, зелёный — у подтверждённого результата.

MAIN VISUAL CENTER: единая карточка плана с заголовком, двумя показателями и быстрым вводом.

COMPONENTS TO REUSE: `VoiceTextInput`, `PlannerScenariosPanel`, текущие action rows, кнопки,
details и design tokens.

MOBILE BEHAVIOR: одна колонка; показатели переносятся, поле занимает всю строку, две команды
остаются доступными с высотой не менее 44 px; горизонтального overflow нет.

STATES: пустой план, существующий план с главным действием, завершённые действия, busy/disabled,
ошибка быстрого создания, loading/error/success сценариев.

APPROVED REFERENCE: отдельный макет не требуется; используется утверждённое направление 2
«Единая рабочая поверхность» и фактическая вкладка активного worktree.

TEST SCOPE: targeted render-тест `PlannerToday`, `npm run verify`, browser QA на desktop и mobile.
Полный E2E не требуется, поскольку команды и browser-взаимодействия не меняются.
