# Корзина и отмена удаления

**Дата:** 2026-09-25

**Статус:** дизайн-контракт определён; реализация ожидает утверждения плана

**Поведенческая спецификация:** [LifeOS trash and reversible deletion](../../superpowers/specs/2026-09-25-trash-and-undo-design.md)

**План:** [Trash and Undo Implementation Plan](../../superpowers/plans/2026-09-25-trash-and-undo.md)

## Дизайн-контракт

```text
FEATURE → единая корзина и немедленная отмена удаления
USER GOAL → безопасно удалять цели, действия и серии и восстанавливать их 30 дней
EXISTING LOGIC → мягкое удаление решений, Pilot sync/outbox, removedAt у серий
PAGE/COMPONENT ARCHETYPE → стандартная страница каталога в текущей рабочей поверхности
SECTION COLOR → jade для восстановления; red только для необратимого удаления и ошибки
ATMOSPHERIC MOTIF → спокойная зона восстановления внутри графитовой оболочки
MAIN VISUAL CENTER → хронологический список удалённых объектов и срок восстановления
COMPONENTS TO REUSE → PlannerWorkspace, AppIcon, строки каталога, диалог, status notice
MOBILE BEHAVIOR → одна колонка, метаданные в несколько строк, меню для permanent delete
APPROVED REFERENCE → YES; «Единая рабочая поверхность» и текущая оболочка приложения
TEST SCOPE → domain/application/persistence/sync, routing, desktop/mobile E2E
```

## Композиция

Маршрут `#/v2/trash` открывается из раздела `Ещё`. Заголовок `Корзина` сопровождается счётчиком и
фильтрами `Все`, `Цели`, `Действия`, `Серии`. Ниже находится единый список по дате удаления от
новых к старым. Строка показывает название, тип, дату удаления, дату окончательного удаления и
основное действие `Восстановить`. `Удалить навсегда` находится в меню строки и требует диалога.

Главный список остаётся единственным визуальным центром. Страница использует текущие графитовые
поверхности, типографику, размеры и focus-ring. Дополнительная декоративная палитра не вводится.

## Состояния

- loading — штатное ограниченное состояние загрузки каталога;
- empty — `Корзина пуста` и пояснение про 30 дней;
- error — inline alert и `Повторить загрузку`;
- restoring/purging — занята только выбранная строка;
- success — строка исчезает после commit, показывается `role=status`;
- expired — строка исчезает после maintenance refresh;
- dependency conflict — строка остаётся и показывает точную исправимую причину.

После удаления на исходной странице восемь секунд доступно `Перемещено в корзину · Отменить`.
Отмена вызывает тот же application-командный контракт восстановления, что и страница корзины.

## Responsive и доступность

На 390/320 px метаданные переходят под название. `Восстановить` остаётся видимым, а опасное
действие сохраняется в меню. Интерактивные области не меньше 44 px. Выбранный фильтр имеет
семантическое состояние, уведомления используют `role=status`, ошибки — `role=alert`. После
удаления строки фокус переходит к следующей строке или заголовку пустого состояния.

Отдельный уникальный макет не требуется: экран полностью собирается из утверждённого архетипа
каталога и текущих shared-компонентов. До завершения нужны browser comparison и проверка desktop,
390 px и 320 px.
