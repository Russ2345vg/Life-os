# Движение в Premium LifeOS

Статус: реализовано и проверено локально. Отдельный визуальный макет не требуется: композиция существующих
страниц и компонентов сохраняется. Эта запись не утверждает новый дизайн от имени пользователя.

## Дизайн-контракт

- FEATURE: визуальные эффекты существующих экранов и контролов.
- USER GOAL: более живой, дорогой по ощущению интерфейс с понятным откликом на действие.
- EXISTING LOGIC: текущие React-состояния, native dialog/details/progress и application-команды.
  Анимации не управляют сохранением, навигацией, фокусом или пользовательскими данными.
- PAGE/COMPONENT ARCHETYPE: существующие workspace, library, contextual editor, feedback.
- SECTION COLOR: текущий graphite + jade; success/error сохраняют семантические цвета.
- ATMOSPHERE: спокойная поверхность, локальный свет на основной кнопке при наведении.
- MAIN VISUAL CENTER: текущее действие, открываемая панель или результат операции.
- COMPONENTS TO REUSE: PlannerSheet, EntityContextMenu, native details/progress,
  существующие кнопки, поля, уведомления и loading placeholders.
- MOBILE BEHAVIOR: более короткое появление; содержимое панели движется снизу на 8 px.
  Mouse hover применяется только при наличии точного указателя.
- APPROVED REFERENCE: YES — [Premium, вариант 2](../references/2026-09-25-premium/approved-direction.png).
  Повторно используется утверждённая композиция, а не старые glass/forest макеты.
- TEST SCOPE: render-тесты Today/forms/library; desktop/mobile E2E фокуса, native dialog resize,
  контекстных меню и reduced motion; один verify после стабилизации.

## Эффекты и границы

1. Заголовки: 6 px + opacity, до 280 мс. Рабочие поверхности: только opacity.
2. Кнопки: press 0.985 за 120 мс; основной CTA получает локальный свет при hover.
3. Поля: мягкий дополнительный контур при фокусе, текущий видимый focus ring сохраняется.
4. Панель редактора: dim/fade; внутреннее содержимое входит сбоку на desktop.
5. Меню и раскрытые блоки: короткое появление без задержки доступности содержимого.
6. Уведомление: появление снизу, корректное центрирование; реальный прогресс интерполируется.
7. Loading: спокойная пульсация только существующего индикатора до окончания загрузки.

`prefers-reduced-motion: reduce` отключает entrance, press, hover movement и loading pulse.
Эффекты не используют animationend, таймеры, новые зависимости или постоянную анимацию фона.
Закрытие немедленное; фокус и scroll не ждут завершения эффекта. Поля ошибок не трясутся.

Нельзя transform на `.planner-v2`, общем контейнере страницы или самом `.planner-sheet`:
fixed resize handle и вложенные уведомления должны оставаться привязаны к viewport.
Popup измеряется при открытии, поэтому его размер не масштабируется. Движение не оставляет
`fill-mode: forwards` или постоянный `will-change` после окончания.

## Состояния

- Loading: существующие placeholders и текст доступны сразу; пульсация не меняет геометрию.
- Empty: существующий текст и CTA, без бесконечной декоративной анимации.
- Error: существующее сообщение появляется без shake и без изменения application-контрактов.
- Success: существующее уведомление появляется только по текущему результату команды.
