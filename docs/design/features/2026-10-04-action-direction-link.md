# Привязка действия к направлению без цели

**Статус:** реализация существующей формы и карточки действия, 04.10.2026.

Пользователь может выбрать для действия направление, не выбирая цель. При создании связь записывается в уже существующее поле `LifeAction.directionId`; в карточке она меняется той же командой сохранения контекста, что и цель. Цель по-прежнему необязательна. Если выбрана цель, направление определяется целью; несовместимые цель и направление не сохраняются. Существующие действия и связи не мигрируют.

`FEATURE → USER GOAL → EXISTING LOGIC → PAGE/COMPONENT ARCHETYPE → SECTION COLOR → MAIN VISUAL CENTER → COMPONENTS TO REUSE → MOBILE BEHAVIOR → APPROVED REFERENCE → TEST SCOPE`

`Направление действия → связывать действие с направлением без цели → LifeAction.directionId и CreateLifeActionDraft → существующая форма/карточка → общий jade → название и контекст действия → select, PlannerActionForm, PlannerActionList → те же поля в одну колонку → стандартный UI, отдельный макет не требуется → domain/application, форма, desktop/mobile browser`

Состояния: «Без направления», выбранное активное направление, цель с автоматически определяемым направлением, недоступное архивное направление и ошибка сохранения. На desktop/mobile используется текущий вид полей и минимум 44 px для элементов управления.
