# Следующий шаг из обзора недели

Пользователь утвердил расширение обзора сообщением «ДЕЛАЙ»: выбирать связанное действие или
создавать новое и назначать дату без новых разделов и режимов мини/макси.

## Дизайн-контракт

- Классификация: новая функция существующей страницы «Цели → Обзор недели».
- Цель: после оценки недели выбрать конкретное действие для цели и запланировать его.
- Состояние: текущий PlanningContext; Goal.nextActionId и LifeAction.plannedDate.
- Команды: SelectGoalNextAction, SetLifeActionPlan и CreateLifeActionDraft. Выбор шага и дата —
  отдельные явные действия; нет составной операции с частичным сохранением.
- Архетип: существующий аналитический обзор; главный визуальный центр — итоги недели.
- Акцент/атмосфера: текущая графитовая premium-оболочка, jade для действий, золото для приоритета.
- Компоненты: planner-details, стандартные controls, PlannerSheet, PlannerActionForm.
- Блок шага свёрнут в карточке каждой активной цели. Доступны открытые связанные действия
  независимо от недели обзора; архивные, удалённые, завершённые и чужие дела исключены.
- Выбранный шаг показывается только по явному nextActionId, без выдачи эвристики за выбор.
- Создание остаётся в обзоре, форма привязана к цели. После создания пользователь явно выбирает
  новое дело следующим шагом. Дату можно назначить в форме или в блоке выбранного шага.
- Выбор шага не меняет главное дело дня. Перенос сохраняет существующий same-date no-op;
  в другую дату дело переносится обычным, без замены главного. Начатое дело не переносится.
- Mobile: один поток, формы grid, controls ≥44 px, стандартная responsive-панель.
- Loading/success/error: существующий run, busy, сообщения и повторный ввод; ошибки выбора
  и даты показываются рядом. Пустое состояние предлагает создать дело.
- Approved reference: существующий обзор утверждён ранее; отдельный макет не нужен для
  стандартной формы на текущих компонентах.
- Baseline: реальная страница /#/v2/goals?view=review, desktop и 390×844. CSS: weekly-review →
  planner-library → planner-master → planner-premium; summary heading 22 px, surface rgb(17,24,27).
- Проверки: projection/render, scoped weekly browser desktop/mobile, npm run verify; полный
  E2E не требуется, общая схема хранения и маршрутизация не меняются.

## Проверка реализации

- Targeted GetWeeklyGoalReview/PlannerWeeklyReview: 8 тестов, exit 0.
- Scoped current.weekly-review.spec.ts: desktop-chrome и mobile-chrome, 2 сценария, exit 0.
  Проверены выбор существующего шага, same-date сохранение главного, ошибка записи выбора и
  повтор, создание и отмена без сохранения, возврат фокуса, дата, reload, неделя в URL и дело
  на «Завтра». Page errors отсутствуют; горизонтального переполнения нет.
- Снимки desktop 1440 px и mobile 390 px изучены: блок свёрнут по умолчанию, главный центр
  и существующая палитра сохранены, раскрытая форма становится одним потоком. Чек-лист №38:
  типографика, поверхности, состояния, доступные подписи и размеры controls соответствуют
  текущей оболочке. Новые эффекты/анимации не добавлены.
- Пользовательский браузерный профиль не заполнялся тестовыми данными; E2E использует
  изолированный профиль. Существующие незакоммиченные изменения сохранены.
- npm run verify: exit 0; 1548 unit/integration, 55 infra, alpha, TypeScript, lint, build,
  форматирование и Git hygiene прошли. Предсуществующие предупреждения lint о voice-input
  fixture и Vite о размере chunk не относятся к этому патчу.
