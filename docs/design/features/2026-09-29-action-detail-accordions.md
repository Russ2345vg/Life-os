# Карточки действия: редактирование, повторение и вклад

Дата: 2026-09-29\
Статус: утверждено пользователем для реализации

## Дизайн-контракт

- **Раздел:** Действия, страница отдельного действия.
- **Цель пользователя:** быстро понимать назначение свернутых блоков и удобно раскрывать редактирование, повторение и вклад в цели без технических маркеров браузера.
- **Существующая логика:** формы, application-команды, данные и семантика `details/summary` сохраняются.
- **Архетип:** компактные аккордеон-карточки внутри detail page.
- **Цвет:** общий графитовый фон, jade для выбранного и раскрытого состояния, золото только для приоритета.
- **Главный визуальный центр:** заголовок действия и последовательность его рабочих блоков.
- **Повторное использование:** `AppIcon`, текущие поля форм, кнопки, токены поверхностей, границ и фокуса.
- **Мобильное поведение:** одна колонка, минимум 56 px для заголовка аккордеона, полноширинные поля и кнопки.
- **Состояния:** свернуто, раскрыто, focus-visible, disabled/busy, конфликт и ошибка формы.
- **Approved reference:** текущий интерфейс и утвержденное направление Premium all screens; отдельный макет не требуется.
- **Проверка:** targeted render test, `npm run verify`, desktop/mobile browser review; полный E2E не требуется, поскольку команды и маршрутизация не меняются.

## Поведение

Карточки «Редактировать действие» и «Повторение и вклад в цели» входят в одну нативную группу `details`, поэтому при открытии одной закрывается другая. Заголовок каждой карточки содержит иконку, название, краткое состояние и единый шеврон. Вложенная настройка повторения использует тот же шеврон без системного треугольника.
