Утверждено пользователем в составе `LifeOS_Utrenniy_Rasporyadok_Master_Plan_v1.0` и запроса на реализацию только MOR-06. Визуальный ориентир — утверждённый экран №7 «Утро завершено».

## Lifecycle

`MorningCycle` становится `READY_TO_WORK`, только когда вода закрыта, холодный душ выполнен или осознанно пропущен, физическая активность завершена или пропущена разрешённым сценарием, а главное действие подготовлено либо явно выбран вариант «Сегодня без главного действия». Mirror остаётся необязательным и не блокирует переход.

Проекция пользовательского состояния:

- `ready` — все управляемые условия выполнены без пропуска;
- `partial_allowed` — есть только разрешённые осознанные пропуски;
- `work_block_started` — пользователь нажал главный CTA, а цикл один раз перешёл в `FINISHED`.

Нажатие CTA не запускает действие, таймер, routine occurrence или рабочую сессию. Оно фиксирует `finishedAt`, сохраняет MorningCycle через существующий optimistic CAS и передаёт навигацию в существующий раздел «Сегодня», где TomorrowPlan/LifeAction уже являются источником рабочего контекста.

## Итоговый экран

Экран использует глубокую графитовую основу, один доминирующий золотой CTA, зелёные подтверждённые статусы и минимум свечения. Desktop-композиция содержит 2–3 компактные зоны; mobile перестраивается в одну колонку с безопасным нижним отступом.

Показываются только реальные данные:

- вода и фактический статус холодного душа;
- число упражнений, выполненных подходов, сумма повторений, сумма фактического времени подходов и длительность физической сессии;
- главное действие, время, готовность, ожидаемый результат и первый шаг, если они есть;
- начало, завершение и длительность утра.

До нажатия CTA моментом подготовленного завершения служит фактическое время перехода в `READY_TO_WORK`; после нажатия история использует сохранённый `finishedAt`.

## История и аналитика

История читает диапазон существующих MorningCycle через repository port и агрегирует первичные `MorningPhysicalExecution.sets`; прошлые подходы не изменяются и отдельное MOR-03 storage не создаётся. Для записи отображаются дата, старт, завершение, длительность, управляемые выполненные/пропущенные этапы, краткий физический итог и главное действие.

Объяснимая статистика 7/30 дней рассчитывается только из завершённых циклов. Средняя длительность обычного утра исключает любой цикл, который проходил в сокращённом режиме. Не считаются гигиена, одежда, чтение фраз, баллы качества, серии или рейтинги.

## Состояния и ошибки

- loading сохраняет геометрию итоговой зоны;
- error показывает причину и retry;
- ready/partial_allowed показывает CTA;
- work_block_started показывает закрытое утро без повторного запуска;
- повторное открытие использует тот же цикл календарного дня;
- новый день создаёт цикл только через существующую явную команду старта.
