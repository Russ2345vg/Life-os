Проверяется рабочий маршрут `#/v2/walks` в активном worktree. Композиция

## Что реализовано

| Область       | Проверяемое поведение                                                                                                                                                                                     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Сессия        | Свободный старт без анкеты, настройка намерения/таймера/сферы, пауза, восстановление после reload, завершение и прерывание. Один локальный active; два active из recovery отображаются для явного выбора. |
| Мысли и итог  | Мысль 1–500 символов, голосовой ввод через общий control, редактирование, обработка, черновик действия с сохранением полного текста, необязательный итог и оценки.                                        |
| История       | Поиск, состояние, намерение, сфера, даты, страницы по 30, фото до 5 МиБ, мягкое удаление и восстановление без очистки мысли.                                                                              |
| Связи         | Старт из «Сегодня», из цели и запланированного действия; возвращение к доступному источнику. Итог переносится в дневник после просмотра и явного сохранения; память получает редактируемый черновик.      |
| План и анализ | Разовый/повторяющийся план через LifeAction/RecurrenceRule, необязательная недельная цель, время и дни прогулок, медиана, пары оценок и переход к исходным записям.                                       |

## Правило №38

Основной центр — старт/продолжение прогулки; вторичные действия уступают ему по весу. Цвет
использует текущую premium-палитру: jade для основного действия, success/error для состояний;
историческое указание №38 о gold как primary заменено утверждённым premium-направлением.
Поверхности, шрифт и интервалы берутся из общей оболочки. Есть loading, empty, error/retry,
success и disabled; интерактивные controls имеют минимум 44 px. Mobile перестраивает сетку в
один столбец; горизонтального скролла документа нет. Структура и статусы читаются без цвета,
новых анимаций нет. Keyboard focus использует общие стили оболочки; ручная проверка с настоящей
мобильной клавиатурой и screen reader остаётся отдельной QA.

## Ограничения до выпуска

1. [Протокол согласования](2026-10-02-walks-sync-compat.md) реализован; пять миграций
   применены к общему серверу, но клиент ещё не опубликован. Пока пространство не повышено
   до формата 2, новая запись при активной синхронизации остаётся fail-closed. Двухклиентный прогон Windows/Android ещё
   нужен для подтверждения межустройственного поведения.
2. Недельная личная цель хранится в IndexedDB и включается в encrypted `user_settings` только
   после подтверждения серверного формата 2. Реальный перенос между устройствами не проверен.
3. История отдаёт не более 30 прогулок за страницу и не включает фото в результат списка,
   однако legacy `walks` cursor читает запись целиком до создания проекции. Для истории с
   тысячами фотографий нужен отдельный индекс/проекция с миграцией и проверкой remote apply.
4. Browser viewport не является проверкой native Android. Ввод через реальную мобильную
   клавиатуру, фоновые переходы native и системные разрешения требуют отдельного прогона.

Изменения не публиковались и не отправлялись в remote. Ручная native QA и двухклиентная
проверка sync остаются открытыми до выпуска.
