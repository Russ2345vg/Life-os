# LifeOS AI: «Что будет, если?»

## Контракт

- **Раздел:** Сегодня. Новый сценарий существующей страницы; графитовая поверхность и общий jade-акцент.
- **Цель:** сравнить два введённых пользователем варианта продолжительностью 5–720 минут с оставшимся планом дня и ближайшим плановым сном. LifeOS не выбирает вариант и не меняет данные.
- **Источник:** `AnalyticsSnapshotReader` только для чтения, `buildTimeScheduleDay` для нагрузки, настройки сна и `calculateNightWindow` для планового времени отхода ко сну.
- **Архетип:** стандартная форма в `PlannerSheet`. Визуальный центр остаётся планом дня; панель показывает два равноправных варианта. Используются существующие кнопки, поля и токены. Отдельный approved reference не нужен.
- **Mobile:** поля и карточки следуют вертикально; панель не создаёт горизонтальную прокрутку. Кнопки не меньше 44 px.
- **Состояния:** пустые/невалидные поля, локальный расчёт, отсутствие настроенного сна или оценок действий, загрузка/ошибка/успех ответа ИИ, отмена запроса.

## Поведение и границы

Пользователь вводит названия и длительности двух вариантов. Локальный расчёт предполагает начало обоих **сейчас** и показывает время окончания, пересечения с будущими действиями с заданным временем, известную суммарную нагрузку невыполненных действий, число действий без оценки и превышение ближайшего планового отхода ко сну. Показатели не предсказывают энергию, успех или фактическое поведение.

После расчёта пользователь видит точный набор кратких фактов и источников, которые будут переданы ИИ. Отдельная кнопка отправляет фиксированный запрос на пояснение через существующий `AiAssistant.askWithContext`. ИИ описывает оба варианта без рекомендации победителя. Изменение поля или повторный расчёт сбрасывает устаревший ответ. Никаких автоматических действий, сохранения или переноса в план нет.

## Проверка

Тесты приложения для расчёта, фильтрации и границ; scoped E2E для явной отправки, отсутствия автозаписи и mobile/desktop; `npm run verify`. Полный E2E оставлен для релизной стадии.
