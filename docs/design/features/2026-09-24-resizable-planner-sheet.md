# Изменяемая ширина общей панели редактора

## Дизайн-контракт

```text
FEATURE → Изменяемая ширина общей правой панели
USER GOAL → Подстроить рабочее место под объём формы и размер экрана
EXISTING LOGIC → PlannerSheet остаётся единым контейнером редакторов; предметные команды не меняются
PAGE/COMPONENT ARCHETYPE → Contextual side sheet
SECTION COLOR → Общий тёплый акцент темы LifeOS
MAIN VISUAL CENTER → Содержимое открытого редактора
COMPONENTS TO REUSE → PlannerSheet, существующие формы и design tokens
MOBILE BEHAVIOR → Панель во всю ширину, ручка изменения ширины скрыта
APPROVED REFERENCE → NO; изменение следует существующему архетипу и предоставленному скриншоту
TEST SCOPE → Расчёт границ, мышь, клавиатура, сохранение между разделами, desktop/mobile
```

## Поведение

- На desktop левую границу панели можно перетаскивать в диапазоне 320–720 px.
- Минимум 240 px основного рабочего пространства остаётся видимым, пока это позволяет окно.
- `ArrowLeft` и `ArrowRight` изменяют ширину с шагом 32 px; `Home` и `End` выбирают минимум и максимум.
- Выбранная ширина хранится локально и применяется ко всем редакторам на базе `PlannerSheet`: целям,
  действиям, сферам, направлениям и индикаторам.
- На ширине до 760 px панель занимает всю ширину экрана. Ручка скрывается, горизонтальная прокрутка
  страницы не появляется.

## Состояния

Состояния loading, empty, error и success принадлежат вложенной форме и не меняются. Если браузер
запрещает доступ к `localStorage`, панель продолжает работать с шириной по умолчанию без сообщения об
ошибке.
