# Направления, действия и повторения

Источник требований: пользовательский DOCX «LifeOS_V2_Единый_патч_направления_действия_повторения», v1.0.
Scope: разделы 01–15 документа; без редизайна оболочки и новых разделов.

## Дизайн-контракт

- FEATURE: функции существующих страниц направлений, действий и выбора действий.
- USER GOAL: создавать работу в контексте направления, выбирать серию один раз, сохранять результат конкретного выполнения.
- EXISTING LOGIC: Direction, Goal, LifeAction, RecurrenceRule, ActionOccurrence, actualResult, completionKey.
- PAGE/COMPONENT ARCHETYPE: существующий рабочий экран и PlannerSheet.
- SECTION COLOR: общий gold-main; повторение — нейтральная метка.
- ATMOSPHERE: существующая природная сцена и дымчатое стекло.
- MAIN VISUAL CENTER: направление или выбранное действие.
- COMPONENTS TO REUSE: PlannerGoalForm, PlannerActionForm, PlannerSheet, VoiceField, VoiceTextArea, существующие list/filter controls.
- MOBILE BEHAVIOR: вертикальный поток, перенос названий, доступные кнопки, прокрутка формы при клавиатуре.
- STATES: существующий loading; пояснение пустого списка; inline error/retry; подтверждение сохранения.
- APPROVED REFERENCE: существующий общий эталон shared-glass/new-direction; отдельный макет не требуется для стандартных форм.
- TEST SCOPE: контекстные связи и persistence, 100 экземпляров и две серии, поиск, выполнение конкретной даты, отдельные результаты, desktop/mobile E2E.

## Решения

Действие без цели получает необязательную прямую связь directionId; при наличии цели контекст вычисляется через неё. Текстовые копии названий не сохраняются. Старые записи читаются с null. Серии и экземпляры остаются в существующей модели; материализация ограничена окном. Отчёт использует существующее actualResult и привязан к completionKey, чтобы запоздалое сохранение не изменяло другое выполнение.

Предсуществующий dirty baseline сохраняется. Никаких push, публикации или изменения пользовательской базы.
