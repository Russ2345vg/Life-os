# Визуальная ясность LifeOS — переработанный пилот

Дата: 30.09.2026. Статус: **утверждён пользователем для реализации 30.09.2026**. Первое предложение меняло главным
образом размеры и отступы, поэтому визуальный эффект был слишком слабым. Здесь текущий интерфейс
с временно изменённым расположением двух блоков и CSS в изолированном профиле Chrome.
На момент снимков продуктовый код не менялся. Временные правила сохранены в
[pilot-overlay.css](pilot-overlay.css); реализация размещает их в исходных CSS-владельцах.

Это снимки приложения после JSX/CSS-правок, без временного `pilot-overlay.css` и без перестановки
DOM через браузерный скрипт. При одном длинном действии верх строки находится на 475 px desktop
и 613 px mobile; утверждённый пилот показывал 474/611 px. На этих размерах горизонтального
переполнения и ошибок консоли не обнаружено.

В изолированной базе создано одно действие «Подготовить важный разговор о планах на следующую
неделю». Дата — системная дата запуска. Снимки сделаны после исчезновения уведомления о создании.
Пользовательская база и данные не открывались и не менялись.

## Что изменилось

| Роль                             | Сейчас                                         | Переработанный пилот                                                      |
| -------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------- |
| Центр Today                      | большая карточка фокуса месяца перед планом    | план первый; фокус месяца в обзорной колонке desktop и после плана mobile |
| Сценарий                         | перед списком действий                         | после списка и блока «Выполнено»; все controls сохранены                  |
| Видимость действия без прокрутки | верх строки: 778 px desktop / 977 px mobile    | 474 px desktop / 611 px mobile при тех же 1440×900 / 390×844              |
| План                             | заголовок 22/20 px; поверхность с тенью        | заголовок 28/24 px; поверхность без тени с верхней jade-границей          |
| Строка действия                  | текст 15 px на фоне плана                      | 16 px, weight 600, отдельная поверхность `--surface-2`                    |
| Пустая кнопка «Создать»          | выглядит почти как активная jade-кнопка        | нейтральная disabled-поверхность; активное состояние остаётся jade        |
| Заголовок панели                 | 36/27.2 px                                     | 34/28 px, отделён от формы тонкой границей                                |
| Раскрытая карточка               | jade border и полоса 3 px, зелёная поверхность | нейтральная граница/поверхность, jade полоса 2 px                         |
| Подтверждение в панели           | `--radius-lg` не определён, визуально 0 px     | существующий `--radius-large`, 16 px                                      |

Это общий язык ролей с явным главным центром, который переносится на другие
архетипы согласно [спецификации](../../features/2026-09-30-visual-clarity.md). Новый шрифт,
палитра или компоненты не вводятся. Состояния, значения и пользовательские действия остаются из
текущего приложения. Перенос фокуса месяца и сценария потребует изменения порядка JSX/DOM, чтобы
порядок Tab соответствовал визуальному; CSS `order` для этого не подходит.

## Baseline и способ проверки

- Активный worktree: `D:/LifeOS-App`; локальный Vite `http://127.0.0.1:4174/`.
- Routes: `/#/v2/today`, `/#/v2/actions`, `/#/v2/diary?period=week&date=2026-09-21`,
  `/#/v2/memory`, `/#/v2/today?action=<isolated-id>`.
- 1440×900 и 390×844: baseline и пилот сняты локальным Chrome через Playwright. Для Today,
  Actions, Diary, Memory подтверждены отсутствие page/console errors и horizontal overflow.
- CSS order в открытой панели: `planner-v2.css` → `planner-library.css`/`planner-views.css` →
  `planner-action-panel.css` → `planner-master.css` → `planner-premium.css` → `diary.css` →
  `memory.css`; также подключены другие feature CSS. Пилотный `<style>` добавлен последним
  только при снимке «После».
- По фактическому DOM в Today и панели подтверждены H1, action row, detail heading и disclosure.
  В `diary.css` есть несуществующий `--space-5`, в подтверждении панели — `--radius-lg`;
  исправление входит в реализацию пилота.
- Встроенный CUA browser tool не запустился (`failed to write kernel assets`, os error 3);
  Playwright использовал локальный установленный Chrome и отдельные browser contexts.
- На обоих пилотных размерах `documentElement.scrollWidth` равен ширине viewport; page/console
  errors не появились. Координаты действия измерены в одинаковом состоянии и данных.

Этот reference утверждён для реализации, но итоговый экран не имеет статуса `LOCKED`:
визуальная приёмка фактической реализации проводится отдельно по
[плану](../../../superpowers/plans/2026-09-30-visual-clarity.md).
