# Быстрый доступ — проверка макета

Статус визуального утверждения: PENDING. Макет не подключён к базе и не является реализацией.

Этот отчёт относится к макету. Проверка внедрённой панели и её текущий статус описаны в
[IMPLEMENTATION-QA.md](IMPLEMENTATION-QA.md).

Источник: действующий Today в активном D:/LifeOS-App, Vite 5186, текущие global/planner-v2/
planner-master/planner-premium. Вычисленные font: Inter/Segoe UI/system-ui, акцент #81cfab.
Baseline desktop/mobile сохранены рядом, как и desktop.png/mobile.png панели.

Проверено через браузер:

- Видимая кнопка и Ctrl+K открывают панель, начальный фокус в поиске.
- Запрос «проект» выдаёт задачи, цель и направление с контекстом.
- Смена даты на завтра обновляет строку и подтверждение внутри панели.
- Создание «Позвонить Сергею» на завтра показывает новую запись и success.
- Ввод в фоновой форме сохраняется после Escape; открытие результата предупреждает об уходе.
- «Остаться» сохраняет введённый текст.
- Ошибка загрузки → повтор → результаты; пустая коллекция и отсутствие совпадений различаются.
- Отдельное состояние загрузки без ложной пустоты.
- Desktop 1440, mobile 390 и 320: горизонтального переполнения нет; проверенные controls ≥44 px.
- Console errors не получены. Desktop/mobile screenshots просмотрены.

По Правилу №38: один центр (поиск/название), текущие tokens, текстовые типы результатов,
нет декоративных графиков/цветов, видимый focus и native dialog. Mobile перестраивается
в полноэкранную панель. Окончательная проверка сохранения/ошибок реальных application-команд,
всех типов фоновых форм, voice input и синхронизации потребуется при реализации.

Формат HTML/Markdown и git diff --check проверяются отдельно. Product verify/E2E не запускаются:
в этом этапе добавлены только specification и демонстрационный reference. Предыдущий патч
account sync остаётся отдельным уже проверенным изменением рабочей копии.
