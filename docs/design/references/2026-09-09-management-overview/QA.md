# Визуальная и функциональная проверка обзора

Дата: 9 сентября 2026. Референсы: 01_current-screen.png, 02_target-overview.png,
03_approved-palette.png и TASK.md в этой папке. Пользователь выбрал макет для реализации;
итоговая визуальная приёмка пользователем ещё не выполнялась.

## Результат сравнения

В реальном LifeOS сохранены глобальное меню, свёрнутая/развёрнутая оболочка и шесть вкладок.
Центральная область следует референсу: шапка, широкий фокус, четыре карточки, единый список
сигналов. Сохраняются данные application query и существующие переходы по идентификаторам.

Палитра локальна: нейтральный дымчатый графит, молочный текст, персиково-золотая главная кнопка.
Кнопка имеет наиболее сильный визуальный акцент; вторичные строки спокойные, без выдуманной
критичности. Результат сравнивался с целевым изображением и палитрой после реального рендера.
Отдельным проходом заменена неуместная иконка раскрытия панели на стрелку и уточнён вес primary CTA.

Desktop 1440×900 и 1280×800, tablet 768×1024, mobile 390×844 и 360×800 проверены через браузер.
Снимки до реализации с пустой системой: `qa/before-overview-*.png`.
Сравнимые снимки после с пустой системой: `qa/overview-*.png` (без data/focus в имени).
Снимки с тестовыми данными после: `qa/overview-data-*.png`.
На широкой центральной области четыре карточки; при недостатке места — две или одна.
Длинное непрерывное имя читается полностью без hover. Вертикальная прокрутка допустима.
Нижняя навигация на full-page снимках видна на высоте viewport; это фиксированный элемент,
а не разрыв контента. Доступность последней кнопки при прокрутке проверена отдельно.

  `public/planning-tomorrow-atmosphere.png`: горы на закате с локальным затемнением.
- Оболочка LifeOS сохранена; дополнительные пункты, профиль и цитата не добавлены.
- Дата отображается текстом из currentDate; декоративный календарный переход не добавлен.
- Статичная пиктограмма фокуса не обозначает процент выполнения.
- Нет строки «Критичных», выдуманных приоритетов и декоративного фильтра: модель их не содержит.
- Сигналы сохраняют порядок query, поэтому отсутствие фокуса не искусственно поднято наверх.

- На снимках присутствуют исключительно изолированные тестовые записи, а не пользовательские данные.

## Проверка №38

- Иерархия: один главный объект и primary CTA; остальные действия вторичны.
- Цвет: золото связано с главным действием, ошибки текстовые с красной границей; fake severity нет.
- Структура: grid с minmax(0, 1fr), согласованные отступы и радиусы; строки сигналов без вложенных карточек.
- Компоненты: SectionPageHeader, AppIcon, существующая иерархия кнопок; расширено семейство иконок стрелкой.
- Состояния: loading, error/retry, empty signals, focus empty/goal/direction, paused session, длинные имена.
- Mobile: перестройка 4→2→1, проверки overflow и touch ≥44px; последняя кнопка не закрыта navigation.
- Доступность: переход к сигналам переносит keyboard focus на заголовок, видимый outline;
  primary активируется Enter, reduced motion отключает анимации и transform.
- Свечение необязательно для понимания; иерархия построена типографикой и композицией.
