## Задания генерации

Общее: production-quality UI mockup LifeOS, русский интерфейс, среда 9 сентября 2026 года,
графит/молочный/персиковый, одно основное действие, спокойная боковая навигация, читабельный sans,
минимум рамок, без вложенных карточек и декоративной аналитики. Контент: текущая задача
«Подготовить концепцию проекта», описание «Собрать идеи и выбрать направление», сессия 18:42,
«Завершить сессию»/«Пауза», далее прогулка и чтение. Данные демонстрационные.

- Первый запрос, «Тихий фокус»: открытая поверхность с крупным названием действия слева,
  простым числовым таймером справа, коротким списком ниже, почти незаметным горизонтом.
- Второй запрос, «Рабочая ясность»: список действий слева, подробности выбранного справа,
  один разделитель, более рабочая плотность, без пейзажа и стекла.
- Третий запрос, «Личный дневник»: одна колонка с широкими полями, выразительный serif только
  у «Сегодня», небольшой таймер рядом с управлением, текстовые строки следующих действий.

## Ограничения

Это выбор направления на одном состоянии desktop. Ни мобильная версия, ни все функции оболочки,
ни полный набор страниц здесь не представлены. Изображения не доказывают responsive,
доступность, реальное сохранение или работу таймера. Первый концепт требует исправления названия
глобального голосового входа на «Голосовые команды». При детализации сохраняется sync indicator.
