## Запуск

Из корня активного worktree:

```powershell
node docs/design/references/2026-10-02-analytics/serve.mjs
```

Открыть [локальный макет](http://127.0.0.1:5173/docs/design/references/2026-10-02-analytics/preview.html).
Сервер слушает только localhost, с выключенными HMR и наблюдением за файлами.
Это исключает сбой watcher на заблокированных отчётах параллельных тестов. После правки нужен
ручной reload. Если порт занят, не завершать чужой процесс.

## Что можно проверить

Переключение показателя графика, недели/месяца, предыдущей недели, переход от KPI и дня к
детализации, возврат к обзору, мобильное меню. Внизу страницы — селектор пяти состояний макета:
готово, неполные данные, первый запуск, загрузка, ошибка. «Повторить» возвращает готовый обзор
и показывает подтверждение обновления.

Даты и записи фиксированные. Месячный пример содержит только записи демонстрационной недели;
детализация времени упрощена до одной строки на день. Это демонстрация композиции и навигации,
не полная модель evidence. Переходы к источникам открывают существующие разделы приложения.
История browser Back, настоящие запросы, инвалидация snapshot и календарные расчёты будут
реализованы и проверены на следующих этапах.

## Проверка макета

- Пять состояний просмотрены на 1600×900 и 390×844; обзор дополнительно на 1280×720 и 360×800.
- Горизонтальное переполнение отсутствует. У проверенных кнопок и селекторов главной области
  размеры не меньше 44×44 px. Подписи вкладок остаются доступными на 360 px.
- Выбор четверга открывает детализацию «24 сентября, 4 ч 30 мин». Проверены возврат,
  предыдущая неделя, месяц, retry и мобильное «Ещё».
- Tab переводит focus с недели на месяц; видимая jade-обводка подтверждена computed style.
- В свежей вкладке итогового макета console errors/warnings отсутствуют.
- Снимки сохранены отдельными кадрами: full-page stitching IAB давал повторяющиеся фрагменты.

Проверка по правилу №38 на уровне макета: один главный график; вторичный контекст ниже;
метрики названы и доступны текстом; текущие shell/CSS/AppIcon; семантические состояния;
loading/empty/error/retry/success/disabled; mobile 2×2 KPI и один столбец; keyboard focus.
Цвет current/primary следует актуальному graphite/jade направлению AGENTS.md, которое имеет
приоритет над историческим пунктом о gold primary в общих правилах. Цвет не является единственным
носителем смысла. Полный инструментальный аудит контраста и screen reader остаётся для реализации.

Команды проверки: scoped TypeScript для preview.tsx (с vite/client), Prettier для этих файлов,
проверка локальных Markdown-ссылок, git diff --check и status. Полные verify/E2E не запускались:
изменены только design-документы и review fixture, не runtime LifeOS.

Визуальное утверждение по New Feature Design Gate в [AGENTS.md](../../../../AGENTS.md)
получено. Этот каталог — reference для проверки продуктовой реализации.
