# «Память жизни»: интерактивный макет

Статус: APPROVED, 29.09.2026. Пользователь явно утвердил макет сообщением «да утверждаю»
после просмотра ленты, редактора и «Мой год». Разрешена реализация UI по этой композиции.

[Открыть макет](preview.html). Переключаются «Лента» и «Мой год», поиск/категории,
добавление и просмотр примера воспоминания. Данные демонстрационные, сохраняются только
до перезагрузки макета. Изображение из существующих assets приложения служит примером фотографии.

Оболочка и controls подключают актуальные global, planner-v2, planner-master и planner-premium
CSS активного worktree. Не является новой реализацией продукта или подтверждением sync/persistence.
Перед утверждением проверяются desktop 1440×1000, mobile 390×844 и 360×800.

Спецификация: [Память жизни](../../features/2026-09-29-life-memory.md).
