# Сценарии задач — проверка интерфейса

Дата: 2026-09-24. Маршрут: `#/v2/today` и переход на завтра.
Это свидетельства реализации, не новый APPROVED reference.

## Проверенное поведение

- Набор собирается по одной существующей задаче, максимум три.
- Частично заполненные наборы сохраняются; доступен поиск по каталогу.
- Переключение наборов не меняет даты и выполнение задач.
- Выполнение общей задачи видно в обоих наборах; reload сохраняет состояние.
- Постоянный набор доступен завтра; дневной остаётся на своём дне.
- Переименование, замена ссылки и удаление набора не удаляют исходные задачи.
- Недоступную ссылку можно убрать. Ошибка записи оставляет прежнее содержимое.
- Отказ чтения после успешной записи не создаёт дубликат при повторном сохранении.

## Правило №38

- Иерархия: при выборе набора его тройка заменяет основной список; меню и дневной обзор
  сохраняют свои роли. Выполненные строки компактны, детали открываются через задачу.
- Цвет и материалы: существующие surface, text, radius, spacing, control и focus tokens.
  Новый CSS не вводит декоративных цветов. В скриншотах используется текущая тема оболочки.
  Общий эталон «Новое направление» изучен; пиксельное совпадение с ним не заявляется.
- Компоненты: существующая строка задачи с checkbox/context menu, VoiceTextInput,
  стандартные кнопки и select. Смысл выбора и выполнения передаётся также текстом/checkbox.
- Состояния: loading не блокирует общий план; есть empty, disabled, success и error/retry.
  Сбой сохранения не стирает введённое название.
- Desktop 1440×900 и mobile 390×844 проверены в Chromium. Переполнения по горизонтали нет.
  Контролы проверены на touch target 44px; у стандартного checkbox используется существующая
  расширенная область `::before` (визуальный квадрат 22px, область нажатия 46px).
- Keyboard: select и следующий контрол получают focus; outline видим. Ошибки имеют
  role=alert, подтверждения role=status. Reduced motion включался в browser check.
- В основном desktop/mobile flow отсутствуют page errors и console errors.
- Структура держится на подписях, порядке и отступах; новый блок не зависит от glow/анимации.
