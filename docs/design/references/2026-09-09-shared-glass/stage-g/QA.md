# Этап Г — проверка остальных экранов

Статус: визуальная реализация и browser-проверки завершены; общая готовность к выпуску ограничена исходными ошибками verify. Визуальный результат принят пользователем 2026-09-09: «давай все устраивает». Последующие исправления проверок и подготовка Windows-пакета описаны в отдельном release-отчёте; результаты ниже сохранены как история этапа Г.

## Изменение

Те же компоненты и CSS переведены на общие `surface-glass`, `surface-glass-raised`, `surface-field`, `surface-selected`, `surface-primary`, `surface-glass-overlay`. Старые визуальные декларации заменены в исходных правилах. Отдельная тема или параллельные компоненты не созданы.

- Управление, альбом/карточка/формы целей, действия и решения.
- День, распорядок, прогулки, сферы, история, вечерняя аналитика, дополнительные разделы, настройки и синхронизация.
- Утренние и вечерние сценарии, подготовка завтра, финальные состояния.
- Убраны повторные фотографии из вечерних сцен и страницы «Завтра». Старые файлы изображений сохранены; существующая CSS-иллюстрация восстановления также сохранена как содержимое.
- 60 типов панелей используют один безопасный псевдослой с размитием. Собственный фон этих панелей прозрачен; повторные заливки устранены. Поля и плотные диалоги используют соответствующий общий материал.
- Подтверждённые/сохранённые состояния зелёные, текущие — золотые, ошибки — красные. Пользовательские цвета сфер сохранены.
- В мобильном вечернем центре три KPI перестраиваются вертикально: текст больше не сжимается в узкие обрезанные колонки.
- Общий заголовок уменьшен до 32–44px. У пустого распорядка и вечерней карточки исправлены отступы, ссылавшиеся на отсутствующий `--space-5`. Убраны категорийные цветные полосы распорядка; текущее состояние сохраняет золотой акцент.
- Пустой альбом переиспользует существующий класс основной кнопки. Добавлен favicon с существующей буквой L; подтверждённая ошибка `/favicon.ico` 404 устранена. Browser theme-color согласован с фоном.

Предметная логика, команды, маршруты и пользовательские записи не менялись. Установленный `D:/LifeOS/lifeos.exe` не обновлялся. Работа ведётся в `D:/LifeOS-App`, ветка `codex/management-overview-redesign-20260909`, локальный dev server `http://localhost:5173/`.

## Проверки

### Browser QA

`shared-glass.screens.spec.ts`: desktop 1600×900, 1280×720; mobile 390×844, 360×800. Проверены основные разделы, настройки, пустой альбом, форма распорядка, утренний и вечерний центры. Отдельно проверяются:

- единый фон и отсутствие горизонтального переполнения;
- отсутствие двойной заливки у видимых стеклянных панелей;
- контрастный материал и высота 44px у обоих CTA пустого альбома;
- автоматический фокус формы, доступность последней кнопки и отмена без сохранения;
- fixed-backdrop занимает весь viewport;
- сводка вечера не обрезает текст;
- отсутствие второй фотографии в вечерней карточке;
- отсутствие console/page errors.

Целевой обзор четырёх размеров: **2/2 passed, exit 0**, 55.35s. После финальной правки отступов и материалов desktop-снимки обновлены повторным прогоном; mobile-снимки обновлены из успешного полного mobile gate.

В пользовательском браузере дополнительно просмотрены альбом, распорядок, прогулки, история, настройки, утро и вечер; диалоги открывались без подтверждения операций. Значения настроек и предметные записи не сохранялись.

### Командные проверки

- Первые связанные проверки: 101 тест; устаревшие визуальные ожидания обновлены и соответствующие 44 теста повторно прошли.
- Последующие связанные проверки после устранения замечаний: **8 файлов / 65 тестов passed**. После последних правок: ещё **4 файла / 40 тестов passed** (голосовое поле, рекомендации прогулок, распорядок, оформление направлений).
- `npm.cmd run verify`: typecheck и lint прошли; full unit завершился **3281 passed / 14 failed**. Шесть ошибок были ожиданиями старого CSS и исправлены последующими scoped-прогонами. Восемь исходных ошибок остаются в семи незатронутых модулях: IndexedDbEveningCycleRepository (2), EveningRitualV2Compatibility, WalkRecordMapper, WalkCaptureRepository, LifeOsIndexedDbSync03, createVoiceCommandController, ApplicationShellPerformance. Полный verify не объявляется зелёным.
- Полный R10 E2E запускается двумя последовательными проектами desktop-chrome и mobile-chrome через канонический wrapper. Это полный набор сценариев, разделённый по конфигурациям браузера; лимиты не увеличиваются, retry отключены.
- Полный desktop: **92 passed / 1 failed / 21 skipped**, 723.90s. Единственная ошибка — неоднозначный CSS-локатор после повторного использования класса CTA в пустом альбоме; локатор ограничен шапкой и доступным именем ссылки, сценарий создания/связей/сохранения сохранён.
- Повторная desktop-проверка после всех продуктовых правок: **19 passed / 3 skipped**, exit 0, 124.01s. Включает исправленный сценарий целей, общий визуальный обзор, голосовой ввод/команды и рекомендации прогулок.
- Полный mobile после всех продуктовых правок: **104 passed / 10 skipped**, exit 0, 737.04s. Все 114 сценариев проекта учтены; пропуски в обоих проектах заданы условиями desktop/mobile.
- Совокупно оба полных проекта проверили 197 применимых сценариев; единственный desktop failure исправлен и подтверждён scoped-прогоном. Это не заявление об одном монолитном зелёном запуске.
- Финальный `lint`: exit 0, 39.99s; 15 существующих предупреждений Fast Refresh в незатронутых TSX/fixtures, ошибок нет.
- `test:infra`: **6 файлов / 55 тестов passed**, exit 0. `test:alpha`: **1/1 passed**, exit 0.
- `npm.cmd run build`: typecheck и production web build прошли, exit 0. Сохранилось предупреждение о JS chunks больше 500 kB; конфигурация сборки не менялась.
- `npm.cmd run format:check`: exit 1 только из-за двух предсуществующих файлов вне этапа — `src/app/App.tsx` и `src/infrastructure/sync/pilot/IndexedDbPilotDeleteRepository.test.ts`. Файлы этого этапа прошли общий формат-проход; финальные Markdown дополнительно проверены отдельно.
- `git diff --check`: exit 0. Diff рассмотрен относительно отдельного исходного снимка этапа Г, поскольку в worktree есть значительный объём предсуществующих изменений. Изменено 37 существовавших на старте файлов; предметные слои в этой дельте не затронуты.
- Итог: визуальная работа этапа Г завершена, известных неисправленных регрессий этого этапа после scoped-проверок нет. Полный `verify` и готовность к выпуску не подтверждены из-за перечисленных unit/format baseline failures. Исправление этих независимых проблем не включалось в редизайн.

Финальное review последних CSS и E2E-локатора также не выявило новых блокирующих замечаний; готовность ограничена результатами gates, перечисленными выше.
