# Главный визуальный эталон LifeOS

[new-direction.png](new-direction.png) — исходный макет пользователя. 2026-09-09 пользователь
объявил его эталоном всего приложения и утвердил реализацию этапов А–В.
Это утверждение направления, а не автоматическое одобрение готового кода.

Фон: [lifeos-forest-atmosphere.png](../../../../public/lifeos-forest-atmosphere.png), 1672×941.
Создан built-in ImageGen из этого макета: удалены UI, надписи, рамки, реконструированы скрытые
участки леса. Это AI-реконструкция, не исходный чистый пейзаж. Сохранены тёмный центр,
горы и персиковое солнце справа, туман и слабые янтарные блики по краям.

Mobile и раскрытые состояния в исходном изображении отсутствуют: они адаптируются из
[общего контракта](../../features/2026-09-09-shared-glass-direction.md).
