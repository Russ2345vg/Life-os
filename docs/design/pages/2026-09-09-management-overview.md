## Дизайн-контракт

FEATURE: оформление существующего обзора и его переходов.
USER GOAL: видеть фокус, сегодняшний день, курс и реальные сигналы.
EXISTING LOGIC: GetManagementOverview; существующие команды назначения в направлениях и целях.
PAGE ARCHETYPE: центр управления; широкий фокус → четыре сводки → общий список сигналов.
SECTION COLOR: локальный нейтральный графит, персиковое золото для главного CTA.
ATMOSPHERE: существующий planning-tomorrow-atmosphere.png с затемнением.
MAIN VISUAL CENTER: главный фокус и один primary CTA.
REUSE: SectionPageHeader, AppIcon, primary/secondary buttons, маршруты разделов.
MOBILE: четыре колонки → две → одна; полные длинные названия; touch ≥44px.
REFERENCE: выбран пользователем; реализация ещё не утверждена визуально.
STATES: loading, error/retry, empty, goal/direction focus, zero/many signals, long titles.
TEST SCOPE: targeted render/application и browser tests, verify, полный E2E для R10.

Никаких категорий критичности, фильтра без основания, декоративного прогресса или новых пунктов
меню. Сигналы сохраняют порядок application query; подписи адаптируются в Presentation.
Дата — текст из currentDate. Счётчики дня включают все объекты, назначенные на дату.
Назначение фокуса использует существующий переход в направления; выбор главного применяется
существующей командой. Возврат на обзор повторно читает общий источник. Отдельного диалога
назначения сейчас нет; его не создаём ради редизайна.

Изображение гор отличается от референса: используется уже имеющийся самостоятельный ресурс,
без нарисованного UI. Общая оболочка и навигация остаются существующими.
