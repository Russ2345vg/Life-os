## Контракт

- Изменение существующего обзорного экрана, раздел «Управление».
- Архетип: компактный каталог. Главный центр — выбранное направление / действие выбора.
- Нейтральный графит, локальный персиковый акцент; без пейзажей и декоративных панелей.
- По уточнению пользователя сохранён материал матового стекла: полупрозрачные нейтральные
  поверхности, статичный мягкий свет фона, backdrop blur и тонкий внутренний блик.
  Меню поднимает стеклянный stacking context своей строки; detail остаётся без редизайна.
- Обычная строка: семейство DirectionSphereIcon, настоящее название, сфера, внутренний
  семантический переход, отдельное существующее меню. У названия с emoji дополнительная иконка убрана.
- Один небольшой блок главного без дублирования; при полностью пустом active-каталоге одно создание.
- Архив — раскрытие без счётчиков. Главный выбор — компактная форма поверх существующей команды.
- Mobile: одна колонка, сфера под названием, перенос любых имён, зоны от 44px, reduced motion.
- Существующие SectionPageHeader, DirectionForm и DirectionMenu переиспользуются.
- Loading/error/retry отличаются от empty; draft сохраняется при ошибке, успех только после команды.
- Визуальный reference: палитра утверждена; композиция задана текстом, отдельного целевого макета нет.

## Источники и границы

GetDirectionsOverview / GetSpheres остаются источником каталога. Удалено eager-чтение всех detail,
которое требовалось только для убранной статистики. Открытие по прежнему selectedId вызывает
GetDirectionDetails. Описание, все группы целей и pulse остаются в DirectionDetail без редизайна.
Domain, Application, persistence, schema, глобальные стили и маршрутизация не меняются.

Канонического URL направления в приложении нет. Переход сохраняет текущий in-memory обработчик;
основная область имеет role=link с клавиатурной активацией, без выдуманного hash-маршрута.
Прямого unset и удаления направления нет; новые бизнес-операции не добавляются.
Archive снимает main, Restore не восстанавливает main — существующие правила сохранены.

Локально исправляются два связанных дефекта: edit формы в списке получает mode=edit;
exception при makeMain показывает ошибку и освобождает busy через finally.

main/change/reload, create/edit/cancel, links/menu/Escape/focus, archive/restore,
сохранность description/goal links, loading/error/retry и failure без потери draft.
