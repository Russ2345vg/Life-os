# Карточка действия и активная сессия

## Открытие действия

Связанное действие открывается из раздела «Действия по решению» мышью или клавишами `Enter` и
`Space`. Отдельный URL не создаётся: панель решения остаётся открытой, а её содержимое
переключается на карточку действия. Кнопка «Назад к решению» возвращает список связанных
действий.

Карточка показывает название, описание при наличии, ожидаемый результат, запланированную дату,
русское название статуса и связь с открытым решением. Внутренние идентификаторы, версия сущности
и коды событий не выводятся.

## Загрузка выполнения

При каждом открытии карточки приложение через прикладные запросы загружает:

- все сессии выбранного действия;
- единственную глобальную незавершённую сессию.

Во время чтения показано сообщение «Загружаем выполнение…». При ошибке доступна кнопка
«Повторить». React-компоненты не создают репозитории и не обращаются к IndexedDB напрямую.

## Запуск

Для готового действия без незавершённой сессии доступна кнопка «Начать выполнение». Для действия
в статусе `in_progress`, у которого сейчас нет активной сессии, показывается «Продолжить новой
сессией». Обе кнопки вызывают `StartLifeActionSession`.

После успешного запуска интерфейс использует возвращённые командой `LifeAction` и
`ActionSession`: действие получает статус «Выполняется», а текущая running-сессия и таймер
появляются без перезагрузки страницы. Для завершённых и отменённых действий кнопки запуска нет.

Если running- или paused-сессия принадлежит другому действию, запуск блокируется сообщением
«Сначала завершите или приостановите текущую работу». Внутренний код ошибки пользователю не
показывается.

## Активная сессия и таймер

Блок «Текущая сессия» показывает состояние, время начала, фактически отработанное время и
суммарную длительность пауз. Для running-сессии отображаемое время обновляется примерно раз в
секунду. Значение каждый раз вычисляется методами `ActionSession`; отдельный накопительный счётчик
в представлении не хранится и ежесекундного сохранения нет.

Формат времени до часа — `MM:SS`, начиная с часа — `HH:MM:SS`. После перезапуска данные и исходное
`startedAt` восстанавливаются из IndexedDB.

## Пауза и продолжение

Running-сессия имеет кнопку «Пауза», которая вызывает `PauseActionSession`. После успеха статус
меняется на «На паузе», рабочее время перестаёт визуально расти, а кнопка заменяется на
«Продолжить».

«Продолжить» вызывает `ResumeActionSession` для той же сессии. Новая `ActionSession` при снятии с
паузы не создаётся. Пока команда выполняется, повторное нажатие заблокировано. Ошибки выводятся
понятным русским текстом, после ошибки управление остаётся доступным.

## История

Если завершённых сессий нет, показано «Работа по этому действию ещё не начиналась». Для каждой
завершённой сессии выводятся время начала, состояние «Завершена», отработанная длительность и
запись о результате при её наличии. Подробная аналитика в карточку не входит.

## Мобильное поведение

На ширине 360–430 px панель прокручивается только по вертикали, информационные блоки и кнопки
укладываются в один столбец, таймер не обрезается, а «Назад к решению» остаётся в закреплённой
верхней навигации. Все интерактивные кнопки имеют высоту не меньше 44 px.
