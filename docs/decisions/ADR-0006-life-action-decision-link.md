# ADR-0006: Связь LifeAction с Decision

- Статус: принято
- Дата: 2026-08-01

## Контекст

Конкретное действие может выполнять принятое намерение, представленное `Decision`, но не каждое
действие обязано возникать из решения. Предметная модель `LifeAction` должна оставаться независимой
от загрузки других агрегатов и инфраструктуры.

## Решение

1. `LifeAction` может существовать без `Decision`.
2. Одно действие связано максимум с одним решением через необязательный `EntityId`.
3. Существование решения проверяет прикладной слой через `DecisionRepository` до создания
   связанного действия.
4. Новое действие можно связать с решением в состояниях `draft`, `planned` и `in_progress`.
5. Новое действие нельзя связать с `confirmed`, `cancelled` или архивированным решением.
6. `LifeAction` не загружает и не проверяет `Decision` самостоятельно.
7. Создание действия не изменяет состояние, версию или предметные события решения.
8. Постоянное хранение связи будет реализовано позднее; текущий адаптер работает только в памяти.

## Последствия

Межагрегатное правило находится в `CreateLifeActionDraft`, а предметные модели не получают
обратных зависимостей. Ошибки отсутствующего и недоступного решения различаются кодами
`decision.not_found` и `action.decision_unavailable`. Уже созданные финальные и архивированные
действия сохраняют связь и остаются доступными запросам репозитория.
