# ADR-0019: редактирование и безопасная отмена действия

## Статус

Принято.

## Контекст

Пользователю нужно исправлять сведения ещё не начатого действия и прекращать незавершённое
действие без физического удаления истории. Операции должны сохранять связь с решением,
завершённые рабочие сессии и границы между presentation, application и domain.

## Решение

1. Редактировать можно только неархивированное `ready`-действие.
2. Изменяются только название, описание и ожидаемый результат; связь с решением, дата, статус и
   время создания сохраняются.
3. После начала выполнения ожидаемый результат действия не меняется.
4. Повтор тех же нормализованных значений не увеличивает версию, не создаёт событие и не вызывает
   сохранение.
5. Безопасная отмена разрешена для `ready` и `in_progress`, но running- и paused-сессии её
   блокируют.
6. Активная сессия автоматически не завершается, а `ActionSessionRepository.save` при отмене не
   вызывается.
7. Отмена переводит действие в `cancelled`, но не удаляет действие или историю завершённых
   сессий.
8. Отмена действия не меняет Decision, его фактический результат или связь действия с решением.
9. Интерфейс требует отдельного подтверждения и обновляет карточку действия и список решения
   сущностью, возвращённой командой, без F5.

## Последствия

- история выполненной до отмены работы и фактически отработанное время остаются доступны;
- после перезапуска редактирование и отмена восстанавливаются из IndexedDB;
- отменённое действие не препятствует созданию другого действия для доступного решения;
- физическое удаление и автоматическое завершение активной сессии не появляются.
