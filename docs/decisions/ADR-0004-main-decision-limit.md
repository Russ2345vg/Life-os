# ADR-0004: Лимит главных решений на дату

- Статус: принято
- Дата: 2026-08-01

## Контекст

Главные решения задают ограниченный фокус дня. Проверка количества не принадлежит одному
агрегату `Decision`: для неё нужны другие решения той же календарной даты.

## Решение

1. На одну `DayDate` разрешены максимум три активных главных решения.
2. Правило находится в прикладном слое как `MainDecisionLimitPolicy`, поскольку зависит от
   нескольких агрегатов, получаемых через `DecisionRepository`.
3. `draft` не занимает место.
4. `additional` не занимает место.
5. `planned` и `in_progress` главные решения занимают место.
6. `confirmed`, `cancelled` и архивированные решения не занимают место.
7. Проверяемое существующее решение исключается из подсчёта по `EntityId`.
8. Правило проверяется при планировании, переносе и восстановлении главного решения до изменения
   агрегата.
9. Превышение лимита возвращает `DomainError` с кодом `decision.main_limit_reached`.

## Последствия

Агрегат `Decision` сохраняет независимость от репозитория и других решений. Все текущие точки,
которые могут занять место на дате, используют одну политику. Отказ по лимиту не оставляет
частично изменённого предметного состояния.
