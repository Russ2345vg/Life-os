# ADR-0024: прямое управление действием из раздела «Действия»

## Статус

Принято.

## Контекст

После появления общей оболочки раздел «Действия» оставался только обзором. Для выполнения
действия пользователь должен был перейти в «День», открыть решение и затем открыть связанное
действие. Это увеличивало число переходов и делало самостоятельные действия фактически
недоступными для управления из основного списка.

## Решение

1. Сделать карточки в разделе «Действия» нативными кнопками и открывать существующую полную
   карточку `LifeActionDetailsPanel`.
2. Не создавать второй набор команд: запуск, пауза, продолжение, завершение, редактирование,
   перенос и отмена используют уже подключённые прикладные сценарии.
3. Вынести координацию прямого открытия в `LifeActionDetailsController`, который получает только
   порты `LifeOsApplication` и не обращается к IndexedDB напрямую.
4. При открытии загружать историю сессий, глобальную незавершённую сессию и доступный контекст
   связанного решения.
5. После изменения обновлять сущность внутри карточки и повторно загружать список выбранной даты
   без F5.
6. Если перенос убирает действие с выбранной даты, закрывать карточку и показывать понятное
   сообщение с новой датой.
7. Добавить локальные фильтры по состоянию; фильтрация не изменяет сущности и не выполняет новые
   запросы к хранилищу.
8. Прошедшие даты оставить полностью доступными для чтения, но скрыть все изменяющие действия и
   управление сессиями.
9. Сохранить один компонент карточки для открытия из решения и из раздела «Действия»; различается
   только подпись кнопки возврата.

## Последствия

- действие открывается и выполняется за один переход из основного раздела;
- самостоятельные и связанные действия используют одинаковый интерфейс;
- предметная модель и схема IndexedDB не изменяются;
- состояние списка обновляется без перезагрузки страницы;
- фильтры остаются временным состоянием интерфейса и сбрасываются при смене даты;
- прямое открытие решения из раздела «Решения» остаётся следующим отдельным вертикальным срезом.
