# ADR-0011: Согласованный запуск LifeAction и ActionSession

- Статус: принято
- Дата: 2026-08-02

## Контекст

Пользовательский запуск работы относится одновременно к действию и его временной сессии.
Раздельный вызов низкоуровневых команд допускает частично начатое состояние и перекладывает на
вызывающий код проверку глобального ограничения незавершённых сессий.

## Решение

1. Пользователь запускает `LifeAction` и `ActionSession` одной прикладной командой
   `StartLifeActionSession`.
2. Действие в состоянии `ready` автоматически переводится в `in_progress` тем же временем,
   которым начинается первая сессия.
3. Действие в состоянии `in_progress` можно продолжить новой сессией после завершения предыдущей;
   повторно действие не изменяется и не сохраняется.
4. Во всём LifeOS одновременно допускается только одна незавершённая сессия в состоянии `running`
   или `paused`.
5. Существующие низкоуровневые команды `StartLifeAction` и `StartActionSession` пока сохраняются.
6. Постоянное транзакционное хранение будет реализовано на следующем макроэтапе. На текущем этапе
   координирующая команда соблюдает порядок сохранения, но два репозитория ещё не объединены
   транзакцией.

## Последствия

Все возможные проверки выполняются до изменения `LifeAction`, получения времени и генерации
идентификаторов. Для `ready` команда сохраняет сначала изменённое действие, затем новую сессию; для
`in_progress` сохраняется только сессия. Обе сущности получают единое время начала операции.
