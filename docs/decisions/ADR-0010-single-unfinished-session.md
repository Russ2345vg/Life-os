# ADR-0010: Единственная незавершённая ActionSession

- Статус: принято
- Дата: 2026-08-02

## Контекст

Одновременные сессии искажают фактическое время работы и не позволяют однозначно определить,
какое действие сейчас выполняется. Ограничение относится ко всему LifeOS, а не только к сессиям
одной `LifeAction`.

## Решение

1. Во всём LifeOS одновременно допускается не более одной `ActionSession` в состоянии `running`
   или `paused`.
2. Приостановленная сессия остаётся незавершённой и блокирует запуск новой сессии.
3. Сессии в состоянии `completed` не блокируют новый запуск.
4. Прикладная команда проверяет наличие незавершённой сессии через репозиторий до получения
   времени, генерации идентификаторов и создания новой сессии.
5. Репозиторий возвращает единственную незавершённую сессию или отсутствие результата.
6. Если хранилище содержит несколько незавершённых сессий, репозиторий возвращает
   `session.multiple_unfinished_detected`, не скрывая повреждение выбором одной записи.

## Последствия

`StartActionSession` отклоняет новый запуск с `session.unfinished_exists`, пока текущая running- или
paused-сессия не завершена. Предметная модель остаётся независимой от глобального поиска, а
completed-сессии сохраняются в истории и не мешают последующей работе.
