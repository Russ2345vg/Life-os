# ADR-0017: подтверждение решения по завершённым действиям

## Статус

Принято.

## Контекст

Завершение конкретной работы и подтверждение результата решения — разные пользовательские
действия. `LifeAction.completed` фиксирует итог действия, но само по себе не доказывает, что
пользователь проверил общий результат решения.

## Решение

1. Решение подтверждается пользователем вручную через `ConfirmDecisionFromActions`.
2. Автоматического подтверждения после завершения `LifeAction` нет.
3. Для подтверждения требуется минимум одно связанное действие в состоянии `completed`.
4. Связанные `draft`, `ready` и `in_progress` блокируют подтверждение.
5. `cancelled`-действия не блокируют подтверждение, но не считаются evidence.
6. `evidenceIds` формируются из всех `completed`-действий в стабильном порядке времени создания и
   идентификатора.
7. Подтверждение сохраняет отдельный фактический результат решения и не изменяет `LifeAction`.
8. После состояния `confirmed` новые связанные действия создавать нельзя, а повторное
   подтверждение недоступно.

## Последствия

- завершённые действия остаются независимыми фактами выполненной работы;
- пользователь явно отделяет выполнение от проверки результата;
- подтверждённое решение полностью восстанавливается из постоянного хранилища;
- presentation работает через прикладной сценарий и не обращается к IndexedDB напрямую.
