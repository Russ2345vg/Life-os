# ADR-0001: Чистая независимая архитектура

- Статус: принято
- Дата: 2026-08-01

## Контекст

LifeOS создаётся заново как самостоятельное веб-приложение. Ранее существовавший плагин Obsidian
решал другую платформенную задачу и не должен задавать архитектуру нового продукта.

## Решение

- Новый LifeOS является самостоятельным приложением.
- Старый плагин Obsidian не используется как технический фундамент; его код, стили, архитектура и
  зависимости не переносятся.
- Предметное ядро не зависит от React, браузерных API и хранилища.
- Интерфейс и будущие платформенные оболочки могут заменяться без изменения предметной модели.
- Внешние механизмы подключаются через порты прикладного слоя и инфраструктурные адаптеры.

## Последствия

Границы требуют явной композиции и небольшого числа дополнительных интерфейсов, зато позволяют
тестировать предметные правила изолированно и заменять UI, хранение и платформенную оболочку.
Преждевременное создание бизнес-моделей и инфраструктуры запрещено: они добавляются только в
рамках соответствующего этапа.
