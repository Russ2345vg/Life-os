# «Что будет, если?» — план реализации

**Goal:** дать пользователю сравнение двух его вариантов по данным LifeOS без выбора и записи со стороны ИИ.

**Architecture:** application-запрос читает существующий аналитический snapshot и возвращает локальный расчёт с ограниченным `AiContext`. UI в существующей `PlannerSheet` вызывает запрос, показывает оба результата и отправляет данные через существующий AI-порт только после отдельного действия.

1. Добавить тесты расчёта в `src/application/ai/WhatIfComparison.test.ts`: границы ввода, невыполненные действия, пересечение с запланированным временем, сон, приватность контекста.
2. Реализовать `src/application/ai/WhatIfComparison.ts` и метод чтения в `ReadAiContext` без изменения snapshot или команд.
3. Добавить форму в `src/presentation/planner-v2/WhatIfAssistant.tsx` и подключить только для страницы «Сегодня» рядом с общим помощником. Расширить существующий CSS для responsive.
4. Добавить browser fixture и scoped E2E для локального расчёта, отдельной отправки, отсутствия записи и mobile.
5. Выполнить targeted tests, `npm run verify`, scoped E2E, browser QA, проверить diff и status. Не выпускать сборку.
