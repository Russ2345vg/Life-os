## Источники истины и границы

- `WalkRepository` / `Walk`: факт завершения, intent, timestamps, pause-aware actual duration,
  вопрос, beforeState / afterState, impact / result, linkedEntity / returnContext.
- `WalkCaptureRepository`, через существующий `GetWalkCaptures`: все мысли, включая processed.
- Decision / Routine repositories: только доступность ссылки и актуальное название источника.
- Никаких History entity, records, stores, миграций, новых зависимостей или копий Outcome.
- Presentation получает application queries; UI истории не получает lifecycle / edit commands.
- История не вызывает Reentry и не меняет Walk, Decision, Routine, captures или исполнения.

## Список

Только completed, сортировка endedAt DESC, id ASC при равных датах. Фильтры: Все,
Свободные, Восстановительные, Размышление. Legacy intent=null остаётся в «Все» с исходным
названием типа; намерение не угадывается. По 20 записей на страницу, простая навигация.
Дата и время начала, режим, фактическая длительность и короткий факт результата.
Нет outcome / result — «Без итога». Нет прогулок — «Здесь появятся завершённые прогулки.»
и «Начать прогулку», ведущая в существующий flow выбора намерения.
Фильтр без совпадений имеет отдельное нейтральное сообщение и сброс фильтра.

## Детали

Режим, дата/время начала, фактическая длительность; вопрос и связь; энергия, напряжение,
ясность до → после (отсутствующие значения: «Не отмечено»); существующие impact и result;
сохранённые мысли с capturedAt и pending / processed. Никаких аналитических выводов.

Decision и Routine имеют безопасные отдельные callbacks навигации без Reentry-команд.
Отсутствующая / удалённая связь не ломает карточку; ошибка чтения связи отключает переход.
Сохранённый Routine sourceTitle — исторический контекст, а не доказательство живой ссылки.
Другие типы linkedEntity отображаются компактно без новых интеграций.
Ошибка чтения самих Walk / captures видима с повтором; не маскируется пустой историей.

## UI и доступность

Графитовая база, золото, спокойный зелёный, компактный журнал без аналитической колонки.
Нативные кнопки/список, focus при открытии и возврате, сохранение фильтра и страницы при
возврате из деталей. Mobile 360 / 390 / 430: одна колонка, переносы, цели касания от 44px,
без horizontal overflow и перекрытия bottom navigation.
