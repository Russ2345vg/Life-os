# Плагины и MCP для LifeOS

Состояние проверено 2026-08-24 в Codex desktop и CLI 0.144.5. Установка и подключение новых
плагинов в рамках апгрейда не выполнялись.

Это исторический снимок, а не требование подключить все перечисленные средства в каждой задаче.
Для Astra выбирай навыки и инструменты по актуальному scope и доступности. Текущие правила
автономности, согласований и проверок задают `AGENTS.md` и `CODEX_WORKFLOW.md`; общие workflow-навыки
применяются с учётом этих проектных правил. Plugin cache не редактируется для настройки LifeOS.

## Использовать сейчас

| Возможность    | Фактическое состояние                             | Польза LifeOS                                                         |
| -------------- | ------------------------------------------------- | --------------------------------------------------------------------- |
| Superpowers    | Навыки доступны в desktop-сессии                  | Планирование, debugging, TDD, verification и review workflow          |
| Figma          | Plugin/MCP доступны, авторизация подтверждена     | Чтение утверждённых nodes и design-to-code после получения LifeOS URL |
| Product Design | Навыки доступны в desktop-сессии                  | UI-аудит и работа с визуальными референсами по явному запросу         |
| Browser        | Plugin включён; browser-control skill доступен    | Ручная QA реального route, desktop/mobile и console                   |
| Playwright     | Локальная devDependency проекта, системный Chrome | Воспроизводимый E2E smoke без зависимости от desktop browser session  |
| Node MCP       | Один stdio MCP подключён глобально                | Программная оркестрация инструментов; проектной настройки не требует  |

Figma доступен технически, но основной LifeOS Figma URL в проекте отсутствует. Поэтому чтение
конкретного node пока не проверено.

## Не устанавливать без отдельного сценария

| Плагин         | Статус                                | Решение                                                                                                                             |
| -------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Codex Security | Доступен в marketplace, не установлен | Подключать для отдельного deep security review или security backlog; текущий gate покрывается code review, tests и dependency audit |
| Sentry         | Доступен в marketplace, не установлен | Не подключать, пока LifeOS не использует Sentry project/DSN и не утверждена telemetry policy                                        |
| GitHub         | Не установлен                         | Не нужен для локального Git; подключать только для PR/issues/remote workflow                                                        |
| Chrome plugin  | CLI показывает не установлен          | Не нужен для E2E: Playwright использует установленный системный Chrome, а desktop Browser уже доступен                              |

## Важное различие клиентов

`codex plugin list` показывает Figma и Superpowers как не установленные в CLI marketplace, хотя их
skills и MCP реально доступны в текущей desktop-сессии из plugin cache. Это разные поверхности
доставки. Не устанавливай дубликаты только ради выравнивания списка CLI; сначала проверяй доступные
skills/tools в том клиенте, где выполняется задача.

CLI также сообщает о доступной версии 0.149.1 при установленной 0.144.5. Глобальное обновление CLI
не относится к project-only изменениям и требует отдельного разрешения пользователя.
