и результаты были проверены; успешные проверки неизменённого релизного кода не повторялись.

- Подписанная Windows-сборка: PASS, 406.56 s.
- В этой задаче повторно выполнены `npm run test:release`: 6/6 PASS, exit 0.
- Release receipt, версии и соответствие updater-подписи manifest: PASS.
- По журналу локальной установки: обновление 1.0.13 → 1.0.20, код установщика 0;
  версия файла и запись Windows — 1.0.20. Снимок 1658 файлов данных до/после совпал.

Незакоммиченные изменения фильтров, Goal/mapper/record, weekly-review и saved-views/trash

## Публикация и публичная проверка

При вызове `release:windows publish` соседняя задача уже опубликовала тот же пакет;
скрипт безопасно отказался перезаписывать существующую версию. Проверено, что все четыре
GitHub assets совпадают по digest с проверенным receipt и релиз публичный, не prerelease,
а latest endpoint возвращает 1.0.20. Описание выпуска обновлено из `docs/releases/v1.0.20.md`.

- [Релиз 1.0.20](https://github.com/Russ2345vg/LifeOS-Releases/releases/tag/v1.0.20).

  SHA-256 `768af6f6cd4fcaa0d2cad6d11df61fa9449172589511491c66be9ef02b77d5ba`.
- Публичные latest.json и installer скачаны; версия manifest и SHA-256 installer совпали.
- GitHub branch и peeled tag проверены через `git ls-remote`: оба указывают на релизный коммит.

Пакет имеет подпись для updater LifeOS, без Windows Authenticode-сертификата.

остаются пользовательской проверкой после скачивания; локальная установка не переносит
данные между устройствами.
