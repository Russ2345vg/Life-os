# Подготовка Windows-выпуска LifeOS 1.0.19

Пользователь запросил публикацию на GitHub для установки на другом компьютере.
Ветка исходников: `codex/motion-release-1.0.19`, база: `d34ff71` (1.0.18).

## Состав

Новые эффекты Premium и достоверное отображение состояния синхронизации вместе с тестами.
Версия согласована в package.json, двух записях package-lock.json, Cargo.toml и Cargo.lock.
Идентификатор приложения, ключ updater, endpoints, зависимости и схема данных не менялись.
Незавершённые weekly-review и quick-access макеты не включены в release commit.

  пропущен без тестового сервера. После него менялись только версия пакета и документация.

  Запущен по release/R12 gate. Owned-порт 4173 освобождён с подтверждением runner.
- `npm run release:windows -- prepare 1.0.19`: PASS, 270.75 с; fresh NSIS x64 и updater signature.
- ProductVersion/FileVersion нативного `lifeos.exe`: 1.0.19.
- Подготовленный receipt проверен по SHA256 всех файлов; manifest содержит версию 1.0.19,
  неизменяемый URL установщика и совпадающую подпись.
- Motion CSS присутствует в production bundle. Desktop/mobile и reduced-motion QA описаны

установщика и сравнением хеша после publish; исходные assets не пересобираются при публикации.
Ключи подписи не выводились и не включены в Git. Подпись updater не заменяет Authenticode.

ручной проверкой пользователя. Сохраняются прежние предупреждения lint о voice fixture,
build о размере JS chunk; сообщение MSVC о создании import library не остановило native build.
